# Ember 0.21.3 发布说明

2026-10-23。框架补丁版本；全部模板版本保持不变。

## 改动与消费方式

框架安装、升级注册完成及编辑器初始化时，自动创建或更新项目根目录 AGENTS.md / CLAUDE.md 的 Ember 受管区块，链接到实际解析包中的公共规则。区块外自定义内容、编码与换行保留；相同内容不重复写入，模板切换不移除入口。失败信息与重试按钮在 Ember/UPM Manager 的 AI Skill 区域。

公共规则要求默认只运行新增或相关部分测试，全量或长时间测试先获明确授权；MCP断连后每隔30秒重试，最多10次，全部失败后停止并请用户确认。冲突恢复技能源及随包bundle同步更新。bundle从已提交源生成，四个既有生成文件仅统一换行以匹配源指纹，无语义变化。

消费项目通过 UPM Manager 升级至 v0.21.3，等待编译/域重载完成；无需补入口或重新部署模板。已有 AI 会话可能需要重新加载规则。只读文件、符号链接、无效编码或损坏标记不会被强行覆盖，修复后可重试。
