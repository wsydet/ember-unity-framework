# Ember Framework 0.12.10 发布说明

日期：2026-09-14。Tag：`v0.12.10`。归属：**框架升级**。

## 在 UPM 管理器中查看更新内容

此前检测到可升级版本后，窗口仅显示版本号与升级按钮，无法知道该版本的改动。
现在每个可升级版本下都有“更新内容”折叠区，默认展开最新版本，其余版本按需展开。

窗口通过已有 Git 凭据对最新固定标签做 bare partial clone，再读取
`Packages/com.ember/CHANGELOG.md`，按版本标题提取对应条目。界面标明日志来源版本，
未发布条目不会作为版本说明；缺少对应条目时明确提示，不借用其他版本内容。
提供“查看该版本发布日志原文”入口，文本不作为代码或富文本执行。

Git 进程及输出读取异步进行，不检出项目资产。最多等待 60 秒，失败可重试，
关闭窗口或重新检查时取消正在读取的说明；同一窗口复用已获取的说明。
失败或没有说明不阻挡升级，加载结果在 Layout 阶段应用以保持重绘控件一致。
临时仓库存放于 Library/EmberUPMReleaseNotes，按请求清理；取消时仍被 Git 占用的残留可随 Library 清理。

## 范围与验证

- UPM 编辑器程序集保持零框架/Odin 引用，不新增 UPM 依赖。
- 新增 5 个离线 EditMode 案例：版本/代码块解析、固定标签中文日志、缺文件与重试、取消/超时后重试、异步完成后的实际 IMGUI 重绘与升级候选保留。
- 已实际从远端 v0.12.9 按上述 Git 方式取得中文 CHANGELOG，确认无需检出 Assets。这是传输验证，不代表 Unity 面板或回归测试执行通过。
- 静态发布检查覆盖版本和 56 项依赖一致性、Git 空白、UPM 程序集独立性、模板及发布字体未变，以及三份共享字体的完整性和两种 autocrlf 干净检出。
- 模板保持 base 0.6.3、source3d-2p5d 0.3.5，父快照、Hash、0.12.0 兼容声明和 GuideModule.Enabled=false 不变；第三方继续使用 ember-v0.11.1。
- 不提交已有字体动态缓存、生成的 slnx、Table 状态及本地模板交接记录。

当前 Unity MCP 不可用，本次未完成 Unity 编译验证。5 个新增测试与消费端交互也尚未执行；没有将此前其他版本的编译确认套用到本次发布。

## 升级与验收

已有项目通过 **Ember/UPM Manager** 升级至 0.12.10，不直接修改消费端 manifest/lock 或 PackageCache，无需重新保存或部署模板。
旧管理器需要先完成这次升级，之后检测到后续可升级版本时才能展示说明；当前没有更新版本时不会额外显示候选版本说明。

验收最新版本默认展开、其他版本展开、中文换行、加载失败重试、关闭取消，以及说明加载失败时升级按钮仍可使用。
请在 Unity 中手动触发编译；如果仍有报错，请将首条编译错误及其完整堆栈发回当前对话。
