# Ember Framework 0.16.0 发布说明

2026-09-28。本次同时更新框架编辑器能力与视觉小说模板。

## 图片资源管理

- `Ember/视觉小说/图片资源管理` 提供 Odin 分类树、按组缩略图和右侧预览编辑；原立绘入口保留。
- 内置立绘、背景和皮肤图片覆盖表。立绘按角色、皮肤图片按皮肤和页面自动分组，支持自建多级逻辑文件夹及 Ctrl / Cmd 多选整理。
- 支持新增 Key、修改源表信息、绑定已有图片和导入 PNG / JPG。导入延迟到保存时执行，校验或烘焙失败时撤回新增图片并保留草稿。
- 分组独立保存，不改变运行时 Key、资源路径、源表 Schema 或存档。其他 Resources 图片列可通过 `EmberImageSourceAsset` 显式接入；不自动收录任意代码拼接的 Key 或固定 Prefab 引用。
- 皮肤图片以 Sprite 加载；已有图片的导入设置不被面板自动修改。九宫格和皮肤布局继续使用皮肤编辑器。

## 模板与依赖

| 模板 | 内容版本 | 兼容框架 | 本次内容变化 |
|---|---|---|---|
| base | 0.7.0 | 0.16.0 | 无 |
| source3d-2p5d | 0.4.0 | 0.16.0 | 无 |
| visual-novel | 0.16.0 | 0.16.0 | 图片管理入口、来源适配、使用文档 |

小说模板通过正式保存和 Bump 封存；兼容声明通过根模板声明和父子同步更新，base / 2.5D 不伪造内容版本升级。第三方依赖、框架技能 bundle 和模板技能内容不变。

## 验证与边界

- Unity 6000.5.4f1 编译通过，发布前 34 项表编辑器 EditMode 回归通过。
- 真实新增 PNG、保存源表和烘焙运行数据验证通过；缺图和非法角色引用均验证了导入撤回、源表恢复。
- 模板内容封存、父子兼容与父快照核对通过；共享二进制、字体配置及技能 bundle 完整性检查通过。
- 面板已在开发项目中打开，三类来源与目录加载正常。未完成所有分辨率下的视觉验收、完整 Play Mode 或消费项目端到端升级。

## 已有项目升级

1. 通过 `Ember/UPM Manager` 选择 v0.16.0 升级框架；不要手改消费项目 manifest 或 lock。
2. 使用小说模板的项目需继续迁移模板 0.16.0。包升级不会自动修改项目 Assets；本次跨 minor，不走 patch 三方增量或“补齐缺失”。
3. 先保护旧模板、新模板与本地定制，再通过项目中心完整部署并恢复业务修改，或对照新版手动迁移相应编辑器文件。不要无备份覆盖项目目录。
4. 验证旧剧情图片加载、新增和替换图片、分组持久化及保存失败提示。没有使用小说模板的项目无需为图片面板重新部署业务模板。

新建项目可直接选择包内 visual-novel 0.16.0。依赖声明见 `Packages/com.ember/Dependencies~/release-0.16.0.json`。
