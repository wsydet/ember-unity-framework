# Ember Framework 0.14.9 发布说明

2026-09-24。本次发布交付已封存的 visual-novel 0.8.0；框架 API、base/source3d-2p5d 和第三方依赖不变。

## 更新内容

- 主 UI 编辑器支持全屏旁白、章节卡、阅读控件及字号/历史弹窗布局和外观。
- 章节卡整体点击渐隐；文字渐显、打字机、立即显示及时间、速度、缓动可配置。
- 彩色二级步骤可展开、折叠、复制、解包和保存成自定义预设；包含隐藏所有立绘、舞台复位和场景收尾。组合仍执行基础指令，复制重映射内部等待。
- LastLight 四段提供 15 组示例和 3 份复用预设，80 条台词与分支不变；运行目录清理旧 Story，测试夹具独立保留。
- 剧情导入、演出优化、导出三个 skill 支持组合及内部参数，最低业务模板版本 0.8.0。
- 修复旧剧情新增文字参数为零引起的 BadText，以及模块销毁接口接入。

## 验证

Unity MCP 编译及 177 项相关回归通过：156 项剧情/运行/存档、8 项正式 Prefab 布局/透明度，以及 13 项实际页面/观察测试（含 Play Mode；最后一项修复后单独复测）。未重新运行全部 645 项测试，消费项目迁移和跨平台观感待验收。

模板版本 0.8.0，父模板 base 0.6.4；内容及封存 hash 为 `92090cf03438c7d73bac80795ede3b17`。最低框架兼容声明保持 0.14.1。工作区无关 BOM、动态共享字体、本机调试与解决方案变更不纳入本次发布。

## 消费项目更新

1. 通过 Ember/UPM Manager 升级框架至 v0.14.9。
2. visual-novel 0.7.x → 0.8.0 跨 minor，不适用同 minor 的模板补丁增量。先备份本地剧情、资源与代码，再按项目中心流程部署并合回定制内容，或人工迁移本次差异。
3. 完成业务迁移后同步模板技能；仅升级 skill 无法为旧业务补上二级步骤能力。
4. 验证章节卡过渡、组合步骤、全屏旁白布局、新游戏和旧存档。演出定义指纹变化可能使旧存档不兼容，保留存档，不直接删除。

仅升级框架不会自动改变已部署 Assets；不要直接修改消费项目 manifest/lock，也不要无备份覆盖本地业务。
