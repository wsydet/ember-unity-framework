# Ember Framework 0.14.7 发布说明

2026-09-23。本次为框架级技能补充，不修改 Runtime/Editor C#、业务模板内容、模板版本或依赖。

## 变更

- 新增框架级技能 ember-template-conflict-recovery（Ember 模板冲突恢复），最低框架版本 0.14.5。
- 依据旧模板、新模板与本地内容三方合并，保留业务改动，备份当前文件并检测并发变化；明确 GUID、EUI、旧基线与部署记录的保护边界。
- 合并后重新预览，由项目中心事务推进版本；完整部署后的恢复要求可信部署前备份。
- 技能清单和包内 bundle 增至 10 项，包含可追溯的技能源提交。

## 验证与边界

- Skill frontmatter、UI 元数据、清单唯一性及隔离消费目录结构校验通过。
- 技能 bundle、共享二进制完整性与字体配置检查通过。
- 未执行真实 Unity 模板冲突演练或消费项目安装验收；本次无 C#、程序集或 Unity 资产改动，不声称新增 Unity 编译/运行验证。
- 本地其他未提交的代码、编辑状态和解决方案改动不属于此发布。

## 消费项目更新

1. 通过 Ember/UPM Manager 升级到 v0.14.7。
2. 在 AI Skill 独立安装与更新中选择 v0.14.7，检查并安装 Ember 模板冲突恢复。
3. 重新加载 AI 会话，使用 $ember-template-conflict-recovery 并提供项目中心生成的冲突日志。

已有框架 0.14.5 及以上的项目也可仅从 v0.14.7 安装技能。本次无需完整重新部署业务模板；已有技能副本不会被包升级静默覆盖。
