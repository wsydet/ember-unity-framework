# Ember 0.24.0 / platformer-2d 0.13.0

本版交付2D关卡制作工作台。框架负责素材登记、尺寸/连接、对象编辑、扩展适配器、隔离试玩事务与业务场景登记；platformer-2d负责正式玩法初始化接线、白盒资源、示例及四类制作Skill。没有修改或升级Windward。

包来源为本仓库 `Packages/com.ember`，发行引用为 `v0.24.0`。模板维护源为 `Assets/Game`，通过正式Save/Bump封存0.13.0，内容指纹 `ff217ca17005f39519049c46a83c138b`。模板保留preview通道。base 0.10.0、source3d-2p5d 0.6.0、ui-game 0.2.0、visual-novel 0.22.1内容不变，正式父级同步兼容0.24.0。历史子模板GUID冲突逐项保留子项，父内容与父快照均未改变。

新增显式依赖：Tilemap 1.0.0、Physics2D 1.0.0、Unity.Collections 6.5.0；第三方包来源与标签沿用0.23.0，不自动同步消费依赖。模板保存同时包含Unity序列化产生的本地化空字段、脚本BOM、构建预筛选字段与动态字体缓存清理；不包含工作区其他UI/FSM功能开发。

## 消费升级与回退

先备份消费项目代码、资源、正式模板身份记录和存档，再通过 `Ember/UPM Manager` 升级框架到0.24.0，等待UPM与编译成功。包升级不会更新已部署Assets。

platformer-2d 0.12.x→0.13.0属于minor结构迁移：保护消费定制，对照旧模板、新模板及本地内容分批迁移；不能直接全量覆盖Windward。接入公开适配器和业务关卡登记后，再通过项目中心同步四类Skill。先跑白盒样例，再做Windward自己的关卡/存档/构建验收。

回退时通过UPM Manager恢复此前框架版本，同时从备份恢复模板业务Assets和身份记录；只降包、不回退模板将留下缺失API。正式存档与本工具测试存档分离。详尽API、程序集、样例与迁移步骤见交接报告及其链接的模板文档。
