# Ember Framework 0.19.0 发布说明

2026-10-15。UPM 发布标签 `v0.19.0`；发布进度见[推进记录](release-0.19.0-plan.md)。

## 交付内容

- platformer-2d 0.4.1 提供与空洞/蔚蓝手感同级的只读内置“通用攻击模板1”，正式三连击、沙袋、陷阱及六帧刀光；支持伤害、受击、无敌、死亡和恢复。
- 完整战斗方案冻结、控制权与 FSM 仲裁、命中批次过滤、联合提交及 Undo/Redo；停顿派生、两种冲刺出招、空冲惯性由隔离配置验证。
- 玩家开发工具提供攻击编辑、命中预览、独立结构复制、白盒尾迹及正式指定方案体验 API；新增攻击 Skill 随模板交付，公共 11 项 Skill 及第三方依赖不变。
- 纳入用户确认的攻击范围/刀光调校、空冲退出速度倍率 0.25、受击动画归位修复，以及攻击中异常诊断与清理测试。
- 公共蓝图编辑器增加 CopySavedLayout，按稳定节点 ID 复制已保存布局，拒绝覆盖目标已有布局，保留源窗口及未确认预览。

## 模板与验证

base 0.8.3、source3d-2p5d 0.5.0、visual-novel 0.20.0 内容不变；platformer-2d 0.4.1 封存 hash 为 373437cccbe9f4ba6e93359da2c8b2fd。四模板兼容声明为 0.19.0。Unity 正式检查三个派生均 Synced，实际内容 hash/封存 hash、父快照与父指针一致；谱系 0 问题，平台编辑记录未过期。

攻击开发批次的 PlayMode 600/600、Editor 114/114、存储 47/47，以及后续调校 8/8、最终故障 1/1 与回滚 2/2 有实际证据；这些是分阶段结果，不声称本次发布重新跑过全量，重叠用例不累加。左右刀光六帧已在正式 GameplayScene 以 0.1 时间倍率捕获并逐张检查。详见[验收矩阵](platformer-combat-acceptance-matrix.md)及[最终补验](platformer-combat-evidence/2026-10-15-final/notes.md)。

T03 的合法派生、缺失/无效身份、消费项目身份及实际跨模板旧窗口草稿恢复留待真实项目验证；P9 不整体放行。发行构建、消费项目迁移不作为已通过。续跑已解除此前 MCP 阻塞：Unity 识别 0.19.0，非编译、scriptCompilationFailed=false、Console 0 errors；发布定向 EditMode job b3b24dd64544476faef44f0246128b43 为 2/2 Passed（5.7387787 秒），覆盖布局复制保护及内置三连击完整装配。默认方案、窗口草稿基线和 Options=1 保留。共享二进制、字体与 11 项/32 文件公共 bundle 静态检查通过。

## 升级

发布完成后通过 Ember/UPM Manager 升级框架，再单独处理模板迁移。旧平台 0.3.x 到 0.4.1 属于 minor 变化，先保护项目定制、草稿、场景、资源 GUID 和布局，不作为普通补丁覆盖。升级包不会自动修改已经部署的 Assets。
