## MCP 不可用时

先检查待编译改动与已有请求，尚未请求时尝试编译；无法送达立即提示用户手动触发编译。结果未知先查询，不能反复提交。随后每隔 30 秒重试连接，最多 10 次，按公共规范恢复或停止依赖操作。

耗尽后最终回复必须说明：本次未完成 Unity 编译验证，请确认 MCP 状态，并请在 Unity 中手动触发编译；若仍有错误，提供首条错误及完整堆栈。即时静态检查可以继续，不使用 Editor.log 轮询、BatchMode 或 dotnet 替代。

## 停止和恢复的范围

必要前置未通过时，暂停依赖它的应用或验收，继续不依赖的文档、分析和工具准备。保留已经有效的成果。回退仅针对本次修改且已确认未被后续编辑的文件；大规模删除、源组件修改和消费项目覆盖必须有准确范围。
