# Ember Framework 0.18.0 发布说明

2026-10-13。UPM 发布标签 `v0.18.0`；本版交付公共状态机与转场、base 新接线及三个派生模板升级。

## 本次交付

- 公共分层 FSM、声明式转换规则、条件表达式及蓝图观察与布局；进入预检、提交、异常停止和诊断边界分开，画布观察不执行条件或隐式修改资产。
- 公共场景转场提供请求级准备、运行、交互完成与取消/清理结果，Loading 依据真实准备状态放行，暂停时使用非缩放表现时间。
- base 提供可选 GameInput、PlayerData 存储及 SceneFlow 接线；三种派生模板同步新父基线，同时保留各自玩法所有权。
- 平台模板交付玩家动作/机制、完整方案工作流与运行冻结、能力与效果、动画、有限规则编辑、独立相机适配及统一玩家开发工具。
- 平台白盒采用单背景面程序化网格：1 单位细线、10 单位主线、世界坐标数字、原点轴及缩小时淡出；覆盖 2048×2048 世界单位。没有纹理、字体对象或逐帧更新脚本；不宣称已经完成 GPU/FPS 基准。
- 平台专属文档、手感调整/动画替换/新增状态三个 Skill 和工具按模板归属隔离；玩家工具入口为 `Ember/Player/玩家开发工具`。

## 交付与验证边界

正式 release/manifest 声明随包交付。第三方依赖及 11 项公共技能内容保持原基线；平台三个技能随模板独立封存。当前模板切换副本、本机 MCP 配置、测试产物和字体运行缓存不纳入发布提交。

消费部署、发行 Build、产物启动、裁剪、跨平台文件系统、长期手感和 GPU/FPS 基准未执行。小说运行中曾出现 DingTalk-JinBuTi 缺少繁体“語/體”的既有警告，未改字体。原R07未明NullReference观察及各阶段素材/新状态人工覆盖限制仍在平台交付记录中保留。

## 消费项目升级

框架发布后，通过 Ember/UPM Manager 升级包，再保护项目定制、场景、资源GUID和布局，分别预览目标模板迁移。框架升级不会自动更新已经部署的 Assets；base及派生模板的新增输入、存储和场景契约需要在消费项目中验证。跨 minor 模板升级不当作普通补丁覆盖。仅更新 Skill 不会安装缺失的模块实现。
