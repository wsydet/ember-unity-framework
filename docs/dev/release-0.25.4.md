# Ember 0.25.4

2026-11-13。基于 v0.25.3 的 Editor 正式身份/扩展资格查询性能与失效修复补丁。发布目标为 origin/main 与 annotated `v0.25.4`；实际发布提交以远端 peeled tag 为准。

## 交付

正式身份按 embedded 编辑记录或 consumer 活动部署记录读取，并验证完整继承链。缓存模板元数据、配置与稳定绑定解析，配置返回深副本、集合只读。条件菜单、项目中心、适配器和试玩 Tick 复用同步检查批次；动态兼容回调和模块条件继续求值，实际操作前重新验证。

事务/回滚、Save、注册/注销、scope 释放、导入、包身份及文件内容变化联动失效，包括缺失输入后来创建或恢复及既有 ContentHashes。文件通知之外增加已知路径的后台合并 stat，周期约 0.5 秒，避免在每帧或每秒同步枚举源码、读取源码或计算 hash。主线程只接收变化结果；实际操作边界仍保留同步复查。

试玩失效判断继续位于 Play 早退之前，沿原 StopCurrent、owner 清理和编辑现场恢复路径退出；Start 保存依赖后再次检查资格和 adapter。Runtime、存档、模板 Assets、父快照和模板封存版本均不变。

实施来源、实际差异和证据见[本任务回执](../tasks/20261113-editor-identity-cache/README.md)，后续接入见[消费说明](../tasks/20261113-editor-identity-cache/consumer-handoff.md)。

## 验证与性能边界

修复最终源码通过对应框架 Unity MCP 主动编译、域重载和已加载程序集核对；直接相关 EditMode **33/33 通过、0 skipped**。覆盖正式身份/父链、配置损坏与外部修改、注册和动态条件、不可污染返回值、内容 hash 变化、事务失效、scope Dispose、试玩失效及旧 owner。已保存真实编辑现场的协议夹具恢复检查通过。未执行全量测试或 Player 构建。

最终微基准：IsEnabled p95 0.0176ms，三项门禁批次 p95 0.0180ms，周期主线程检查 p95 0.1646ms。预热区间无新增 JSON 读取、模板枚举或 hash 构建。启用态另以只在内存中的待审阅配置验证，prepared resolution p95 0.0479ms；没有保存或重新绑定真实项目配置。这些数据不是游戏 FPS，也不是 Windward Trial Tick 的验收值。

完整源码同步 stat 保留于实际操作边界，本轮 p95 77.87ms，环境波动时曾更高；此成本单列，不属于周期主线程稳态成本。文件变化检测基于通知、已知路径时间戳/长度与目录变化，不声明检测恶意保留全部元数据的内容替换。正常调度下的外部配置及源码变化在定向用例 1.1 秒观察窗口确认。

框架当前 topdown-2d 正式编辑身份 0.1.2 与旧配置 0.1.1 不匹配，保留安全拒绝。真实启用态产品 Play、真实模板切换、UPM 来源切换、Windward 前台四条件、邻房/死亡/继续及 GPU 数据尚未验证；不得将本版描述为已解决 Windward 整体低帧率。

## 发布候选

复用上次干净发布工作树，从远端 v0.25.3 的 `e31fedd240678d82dbd6fdb71f79a77d8deba70f` 准备候选。本批 19 个源码/meta 文件与实施验证指纹一致；修改前内容与发布基线一致。其余 763 个包源码文件仅存在另一个工作流任务的两份规则同步实现/测试差异，已审阅其仅涉及规则入口文案和文档存在性检查，候选保留 v0.25.3 版本，未混入本版。此差异及验证环境见[源码对照](../tasks/20261113-editor-identity-cache/evidence/release/source-base-comparison.json)。

发布阶段再次核对 0.25.4 包解析、编译/域重载及程序集，在 0.25.4 下补跑相同 33 项定向用例，33/33 通过、0 skipped，约 12.99 秒；七模板实际内容与六份父快照/指针一致；staged 共享二进制及 autocrlf=false/true 检出、字体配置、12 技能/34 文件 bundle 检查全部通过。旧 Windows PowerShell 5 对 UTF-8 无 BOM 的 GBK 误解码失败已纠正为 PowerShell 7 检查，不改写或重建技能。依赖与检查原始结果见任务 evidence/release。当前开发分支和其他任务的修改不在本版选择性提交中。

第三方依赖、七模板的版本/hash/父基线与 0.25.0 兼容声明、12 项公共技能 bundle 均沿用 v0.25.3。发布声明和 manifest 仅推进框架 tag，不重建未变的技能，不保存/Bump/部署模板。

## 消费接入

消费项目经另行授权后通过 **Ember/UPM Manager** 升级至 v0.25.4，核对实际解析包版本/路径及本轮编译。框架 Editor 源码内容身份变化可能使旧扩展组合按设计拒绝；先展示消费项目实际扩展/Skill 发现/hash 预览差异，独立授权重新绑定，不自动签收。

不手改 manifest/lock、不修改 PackageCache，不自动重新部署模板或升级 Windward。升级后按原方案补齐普通/试玩、项目中心开/关的同环境前台四条件和直接相关功能复验，保护隔离存档、正式进度、玩家手感、机关时序与一跳集合。框架发布与消费端性能验收分开记录。
