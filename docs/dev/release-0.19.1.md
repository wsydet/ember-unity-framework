# Ember 0.19.1

2026-10-15 发布 visual-novel 0.20.1 的图片分类与统一导入工作流。

## 交付范围

- 新增视觉小说模板技能 `ember-vn-sync-images`。用户提供图片文件或目录，AI 查看内容并匹配项目旧图，分类新增、更新、同内容及待核对。
- 本地页面提供用途、角色、剧情字段和新旧图对照、差分警告、已知引用，预览完整计划后一次确认全部。
- `ember-vn-import-images` 与 `ember-vn-replace-images` 接受统一编排回执，继续使用各自的执行、备份和验证规则；单独调用仍使用各自页面。
- 统一服务复用两项原技能计划校验，额外检查跨组目标冲突及源范围完整性。确认后文件变化使计划失效；取消与离线草稿不授权写入。

视觉小说模板经正式 `SaveTemplate` 保存并 Bump 到 **0.20.1**，封存 hash 为 `3836ccbfe60bda104a07e8ab15ff555c`，父基线保持 base 0.8.3。其余模板内容与所有兼容声明沿用 0.19.0 发布。第三方依赖和 11 项公共技能 bundle 不变。

## 验证与边界

- 本轮 8 项隔离 Python 回归通过：单回执双计划、取消终态、离线阻断、选择变化、项目变化、跨组冲突、源范围遗漏与警告确认。
- 浏览器用生成的测试图片验证新增背景与替换旧图混合选择、旧图显示、引用影响勾选、合并计划预览、一次提交，随后命令行 verify 成功。没有导入真实业务素材。
- Unity 正式模板资产、meta/GUID、实时/封存 hash 校验全部通过，三个派生模板父同步状态均为 Synced。
- 本轮没有修改 C#；Unity 刷新后项目编译状态未失败、未编译中，检查时控制台无错误。用于反射检查的临时代码曾因内部 API 可见性报错，改为正确的反射标志后校验通过；未写入项目脚本。
- 发布前另执行技能头、共享二进制、共享字体配置及公共技能 bundle 校验，结果以本次发布执行记录为准。
- 发布检查结果：55 个技能头零错误，共享二进制（含两种 autocrlf 检出）及字体配置通过。公共 bundle 原 Check 命令在当前工作区受模板发现副本影响，在干净稀疏检出中仍受历史混合 CRLF/LF 字节差异影响；未重建无变更 bundle。替代逐文件校验确认全部 bundle SHA256 与 manifest 一致、无额外文件、公共源 Git blob 与 bundle 仅换行差异、sourceCommit 存在。该命令限制如实保留，不声称原 Check 命令成功。
- 未验证真实素材写入、消费项目升级、发行构建或跨平台画面，不沿用历史测试数量作为本轮结论。

## 消费方式

先通过 `Ember/UPM Manager` 升级到框架 0.19.1，再通过项目中心的“模板专属 AI Skill”预览并更新技能。已有兼容视觉小说项目可独立更新技能，无需完整重新部署业务模板。保留本地修改的备份并重新加载 AI 会话。

本次不新增 PlayerData、GameInput、SceneFlow、Loading 或场景运行行为。这些项目 Assets 相对 Git 的差异已核对为与原 visual-novel 0.20.0 快照相同的加载副本，不纳入新的业务改动。
