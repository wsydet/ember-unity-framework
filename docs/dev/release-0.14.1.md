# Ember Framework 0.14.1 发布说明

2026-09-22。发布标签 `v0.14.1`。用户已授权提交并发布；消费项目验收待完成。

修复三个模板沿用 `frameworkVersion: 0.13.0` 导致 0.14.x 框架兼容检查失败的问题。框架包版本及三个模板的兼容声明统一为 `0.14.1`。

模板内容版本仍为 base 0.6.4、source3d-2p5d 0.3.7、visual-novel 0.7.0。此修复仅推进兼容元数据，不修改模板 Assets、内容 hash、父版本或父快照，也不构成新的模板内容封存。第三方依赖与 0.14.0 一致。

本地检查覆盖 JSON 解析、版本对齐、发布清单与模板元数据一致性及父子元数据关系。未重新执行 Unity 编译、运行或消费项目验收，兼容声明不代表新增运行验证。

发布 `v0.14.1` 后，已有项目通过 **Ember/UPM Manager** 检查更新并选择 0.14.1。不要手改消费项目 manifest 或 lock。仅修复模板兼容提示无需重新部署已有业务 Assets；升级框架不会自动覆盖已部署模板内容。
