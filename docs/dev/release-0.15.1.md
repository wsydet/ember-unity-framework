# Ember Framework 0.15.1 发布说明

2026-09-28。本次为框架级技能修复，模板及其兼容声明沿用 0.15.0 发布，Runtime/Editor、业务 Assets 和第三方依赖不变。

## 变更

- 模板恢复支持完整 O/N/L 快照、原始字节验证、分页分类与大量本地修改的分批处理。
- 快照包含五个受管目录、本地新增及删除状态、二进制、目录 `.meta`；额外部署副作用按实际范围另行备份。
- 恢复清单记录候选、决策、写入前状态及结果；中断后检查 hash 再续跑，保护部署后新改动。
- 快照工具只做备份、验证和分类；语义合并和恢复由技能流程完成，不提供一键自动迁移保证。
- 包内 10 项框架技能 bundle 由已提交维护源生成；不手工修改发布副本。

## 验证与边界

- 技能 bundle、共享二进制完整性和字体配置静态检查通过。
- 6 项快照回归通过；符号链接测试因当前主机权限跳过。技能格式校验通过。
- 未执行真实消费项目安装或完整模板升级恢复，也未进行超大工程性能压测。
- 本次没有 C#、程序集或 Unity 资产改动，不声称新增 Unity 编译或运行验证。

## 消费项目更新

1. 通过 Ember/UPM Manager 升级框架到 v0.15.1。
2. 在 AI Skill 独立安装与更新中选择 v0.15.1，显式更新 Ember 模板冲突恢复，并重新加载 AI 会话。
3. 使用 $ember-template-conflict-recovery 协助后续模板迁移；需要运行快照工具时使用 Python 3。

已有框架 0.14.5 及以上也可单独从 v0.15.1 更新此技能。已有技能副本不会随包升级静默覆盖。本次模板内容没有更新，无需完整重新部署模板。
