# Ember Framework 0.14.8 发布说明

2026-09-24。本次发布交付 visual-novel 0.7.5（合并 0.7.4 与 0.7.5 修复），框架 API 和第三方依赖不变。

## 更新内容

- 当前小说通过资源引用选择，支持资产改名、移动；存档按稳定剧情 ID 定位。
- 编辑器节点试播固定状态区高度，避免主视觉画面随内容上下移动。
- 统一主菜单、设置、存档 UI；正文居中，姓名与正文同色并以竖线分隔。
- 设置使用普通遮罩弹窗，保留下层阅读画面；滑条显示字/秒、秒、音量百分比与效果档位。
- 新游戏显示阶段加载进度，首个可读画面就绪后再揭幕；快速读档保留原有无进度遮挡。
- 章节标题使用不透明全屏底色与中央文字，整屏点击推进，结束后恢复对白布局。

## 发布与验证

- com.ember 0.14.8 / visual-novel 0.7.5；父模板 base 0.6.4。
- visual-novel 内容及封存 hash：0bfb674b190aeb9d16a0a233cfcec7dd。
- base、source3d-2p5d 内容版本及 hash 不变；模板最低框架兼容声明保持 0.14.1。
- Unity MCP 编译无错误；144 项 EditMode 回归通过，含设置叠层配置与数值、加载进度模式、16:9/4:3 章节卡与布局恢复。
- 正式 Prefab 离屏渲染已检查。完整 Play Mode 端到端曾在模式切换时因 MCP 会话断开中止，本轮不计为通过；消费项目升级与平台观感仍待验收。
- 工作区既有的框架脚本 BOM 和解决方案改动不纳入本次发布。

## 消费项目更新

1. 打开 Ember/UPM Manager，检查并升级至 v0.14.8。
2. 打开 Ember/项目中心，针对已部署的 visual-novel 0.7.x 预览 0.7.5 补丁增量更新。
3. 保留本地剧情与业务改动，逐项处理冲突后应用；可使用 Ember 模板冲突恢复技能协助合并。
4. 在 Ember/视觉小说/当前小说 选择本项目小说；检查新游戏、旧存档、设置弹窗、章节卡和编辑器试播。

仅升级框架包不会自动更新已部署的 Assets。0.6.x 等跨 minor 模板需先保护本地修改，再按项目中心的迁移流程处理；不要直接修改 manifest 或 packages-lock，也不要用完整模板覆盖代替冲突合并。
