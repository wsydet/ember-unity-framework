# Ember Framework 0.14.10 发布说明

2026-09-24。本次交付 visual-novel 0.9.0；框架 API、base/source3d-2p5d 和第三方依赖不变。

## 更新内容

- 整数赋值、加减乘除取模及变量操作数，适用于收入、消费、属性与事件计数。校验声明、类型、除零和溢出。
- 闭区间随机整数，配合已有条件分支表达百分比、权重和次数事件；具体数值、事件优先级和重置规则由消费项目配置。
- 检查点 schema 7 保存随机状态；恢复稳定节点不重复执行扣费或随机抽取。旧存档沿用兼容校验，包含随机逻辑的剧情不接受缺少随机状态的旧检查点。
- 台词支持显式变量绑定，保留源文本并采用单次替换；动态绑定暂不与文字节拍混用。
- 剧情导入技能增加整本工作表审计、快照完整性检查和复杂逻辑映射。策划中未确定的产品规则保持待定，本次没有导入源剧情。

## 验证

Unity MCP 编译通过。70 项剧情运行、检查点与变量相关回归通过；随后新增四项概率边界测试，最终 19 项变量逻辑专项通过，两轮结果部分重叠。模板谱系和技能同步检查通过。未重跑完整测试集、Play Mode、消费项目迁移或跨平台验证。

visual-novel 版本 0.9.0，父模板 base 0.6.4；内容及封存 hash 为 `bd18ed6a62bb2be51a9ef43d14b9a4ce`。最低框架兼容声明保持 0.14.1。工作区无关 BOM、动态共享字体、本机调试与解决方案变更未纳入发布。

## 消费项目更新

1. 通过 Ember/UPM Manager 升级框架至 v0.14.10。
2. visual-novel 0.8.x → 0.9.0 跨 minor，不适用同 minor 模板补丁增量。先备份本地剧情、资源与代码，再按项目中心流程部署并合回定制内容，或人工迁移本次差异。
3. 完成业务迁移后同步模板技能；只升级技能不能让旧业务获得数值与随机指令。
4. 验证数值变化、概率边界、存读档及旧剧情。定义指纹变化可能使旧存档不兼容，应保留存档再检查兼容性。

仅升级框架不会自动改变已部署 Assets；不要直接修改消费项目 manifest/lock 或无备份覆盖业务。
