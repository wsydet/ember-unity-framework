# Ember Framework 0.14.14

本次在 v0.14.13 基础上发布 visual-novel 0.14.0，保留分段 BGM、自定义节点、开场段落、多语言即时切换与安全区功能。模板封存 hash：`2ed3c7e22df42fd4ed2f921c8313ffdd`。base、source3d-2p5d 与第三方依赖不变。

## 变化

- UI 皮肤编辑器：从基础外观、已有皮肤资产或旧配表皮肤复制独立素材；支持批量替换、九宫格、比例、颜色/透明度、多尺寸预览、导出 PNG 与剧情关联。入口：Ember → 视觉小说 → UI 皮肤编辑器。
- 新增 `ember-vn-edit-skin`，与窗口共用编辑和预览接口；业务模板兼容下限为 0.14.0。
- 姓名输入节点在编辑态试播中显示输入框和确认入口，提交后继续剧情，不启动正式游戏 UI 管理器。
- 存档槽位隐藏章节内部 ID，缺少摘要时不再回退显示台词 ID。

## 验证

Unity MCP 恢复连接后，合并源码无编译错误；保留两个既有 UAC1001 序列化警告。6 项专项 EditMode 测试通过，包含 4 项皮肤复制/替换/撤销/恢复与边界测试，以及 2 项姓名输入预览提交测试（实际名字、空白默认名）。正式 SaveTemplate → Bump、模板谱系与技能同步通过；共享二进制、字体配置、Skill 格式与差异静态检查通过。

此前两个项目各 4 项皮肤回归通过，旧配表皮肤复制 100 个图片位置且资源检查通过，主菜单、阅读页与字体弹窗预览已检查。本次没有重跑完整 Play Mode、全量测试或消费项目升级，不将此前检查当成本次端到端验收。

## 升级

通过 Ember/UPM Manager 升级至 v0.14.14。visual-novel 0.13.x → 0.14.0 跨 minor，需保留产品定制并迁移，不能按补丁增量覆盖业务 Assets。仅升级 Package 不会自动部署编辑器源码；完成业务迁移后通过项目中心预览并更新模板技能。

框架版本、固定 Git tag、依赖 manifest 和正式模板版本/hash 见 `Packages/com.ember/Dependencies~/release-0.14.14.json`。
