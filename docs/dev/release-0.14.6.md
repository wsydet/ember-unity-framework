# Ember Framework 0.14.6 发布说明

2026-09-23。本次以框架 v0.14.6 交付视觉小说模板 0.7.3 的技能说明更新。
base 0.6.4、source3d-2p5d 0.3.7、第三方依赖及模板框架兼容声明保持不变。

## 变化

- 剧情导入：实际打开页面，选择工作表、行范围、目标剧情及五列/角色/资源映射。
- 演出优化：实际打开页面，选择剧情范围、强度与逐位置效果方案，展示参数、等待与复位安排。
- 剧情回写：实际打开页面，选择剧情范围、目标工作簿与新页名称，预览完整导出内容。
- 三者统一要求提供可点击链接，支持草稿、提交、取消，回读与计划和指纹一致的明确提交后再执行。
  用户已经提供的信息预填；页面提交后无需重复聊天许可。图片导入既有页面保持不变。

本版只更新技能说明，三个流程的 HTML 与本地回执服务由代理在执行技能时生成，
没有新增固定页面脚本。选择页面的真实交互与消费项目端到端行为仍待验收。

## 验证

- 使用 Unity MCP 正式 SaveTemplate → BumpTemplateVersion 封存 visual-novel 0.7.3，
  实时 hash 与封存 hash 一致，正式同步后的四项技能发现副本与技能源一致。
- 快照内容差异仅三个 SKILL.md，其他业务内容保持原快照。
- 三项技能元数据、引用及 git diff --check 检查通过；通用技能 bundle 检查通过（9 项 / 24 文件）。
- skill-creator 的 quick_validate.py 缺少 PyYAML，未运行完成；使用元数据和引用静态检查替代。
- 共享二进制与 autocrlf=false/true 检出完整性检查、共享字体配置检查通过。
- 本版无 C# 修改，未新增或重跑 Unity 测试；不沿用上一版本的测试通过数。
- 未更新任何消费工程，未进行页面端到端验收。

## 更新

1. 通过 Ember/UPM Manager 将框架更新到 v0.14.6。
2. 在项目中心打开“模板专属 AI Skill”，预览并执行独立技能更新，保留现有业务内容。
3. 重新加载 AI 会话，让客户端发现更新后的技能。

此次仅技能说明变更，无需完整重新部署业务模板。派生模板读取自身封存的技能源，
不会自动继承最新父模板技能；派生作者需先按正式父子同步流程保存并封存对应更新。
