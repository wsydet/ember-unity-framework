# 引导编辑器使用

打开 `Ember → 引导 → 引导编辑器`。可拖入已有 GuideDefine、双击 Project 中的定义，或点击“新建引导”。Inspector 中也有“打开引导编辑器”入口。

顶部菜单仅在 `GuideModule` 的 `[EmberModule(..., Enabled = true)]` 时显示；设为 `false` 后隐藏。修改标记并完成 Unity 编译后生效，与模块装配使用同一开关。此规则只控制顶部菜单，已有引导资产仍可通过 Inspector 或双击编辑。

## 编辑步骤

左侧按实际执行顺序排列步骤，拖动把手排序；“新增步骤”创建空步骤，“复制选中”深复制条件和参数，底部减号删除选中步骤。右侧填写中文步骤用途、开始和结束阶段；支持 Ctrl+Z 撤销，工具栏“保存”只保存当前引导资产。

- **开始事件**：等待开始条件时，哪些事件会唤醒检查。
- **开始条件**：可跳过整条引导、跳过当前步骤或允许开始；未设置开始执行条件时直接开始。
- **开始执行器**：进入步骤后依次执行，例如显示小手、打开页面或延时。
- **结束事件和条件**：收到事件后判断完成、取消或重试。**完成当前步骤的条件为空时会立即完成，不会等待结束事件。**
- **结束执行器**：完成步骤时依次执行。

条件下拉可直接选具体条件，也可选“全部满足（AND）”或“任一满足（OR）”并添加子条件。展开“参数 / 子条件”填写内容。类型切换时创建对应参数；同结构的页面事件保留参数，AND/OR 切换保留子条件。旧资产缺少或错配参数时显示“创建 / 重建参数”，不会在浏览时自动改写。

## 页面与节点

“选择页面（中文用途）”读取业务 GamePages 定义和 EUIBinding 用途，填入准确的 EUIPageDef.PrefabPath；打开页面执行器同时填入该定义的层级和页面类型。自定义资源路径仍可直接输入。当前打开页面执行器支持 MainPage、Popup、FullScreenPopup、TopMost；其他类型会在配置检查中提示。

“选择目标节点”显示该 Prefab 的节点层级，但保存实际节点名称，与现有 GuideUtils 的递归查找保持一致。相同名称的多个节点目前不能唯一定位，应调整节点名称。UI 点击事件需要业务调用 `NotifyButtonClick`，编辑器不会自动给所有按钮接线。

## 示例：等待一秒后进入下一步

1. 新增步骤，命名“等待主界面稳定”。
2. 展开开始执行器，添加“延时”，等待秒数填 `1`。
3. 展开结束事件，添加“延时结束”。
4. 完成当前步骤选择“由指定事件触发”，参数中的触发事件选择“延时结束”。
5. 点击“检查配置”，核对提示并保存。

编辑器配置检查覆盖缺失参数、无效类型、空条件组、没有完成唤醒来源等常见问题，不替代游戏中的运行验收。模块仍需在 GuideConfig 注册定义、启用 GuideModule 并由业务初始化和启动。

## 验收与模板保存

在 Unity 中手动触发编译后，运行 EditMode 下的 `Game.Guide.Editor.Tests`；手动验证新增、嵌套条件、复制后修改、拖动排序、撤销、保存及重新打开资产。窗口在运行模式及非 Assets 可写资产上禁用编辑。

本轮编辑器已由用户通过模板面板保存至 base 0.6.3 并同步至 source3d-2p5d 0.3.5，随框架 0.12.7 发布。两个模板的 GuideModule 默认保持 Enabled=false；业务项目需要时自行启用并编译。升级框架包不会覆盖已有业务 Assets，既有项目采用新模板内容需另行按项目中心的模板流程处理并核对业务改动。
