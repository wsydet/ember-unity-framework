# R4 为 UI 游戏与 base 接入正式界面背景

2026-11-18，用户发来 UI 游戏“步骤玩法 · 1920 × 1080”截图，要求一起修正 UI 游戏与 base，说明“其他模板没问题了”。用户随后明确澄清：“不是，我的意思是能看到unity默认背景，当时这里好像没处理”。问题是默认 Unity 天空和地平线出现在真实界面及玻璃采样中。此前把反馈理解为玻璃过透的判断已被澄清替代。

- R01／R02／R03、AC02／AC03：检查实际 base 和 UI 游戏的首屏、玩法、设置和 UI 游戏结果，找出默认 Unity 背景从哪个相机或页面路径可见。两个模板通过现有合适的项目背景接线呈现有意设计的底景。优先复用已有合适资源和正式机制，保留玻璃材质参数、版面和控件契约。
- R04／R05／R07、AC04／AC05／AC06／AC07／AC09：背景在正式入口、转场与相关面板的横屏、窄屏、竖屏全覆盖，玻璃照常采样、交互与清退正常。不可将 Unity 默认天空换成遮挡游戏或转场的前景层。保留 ui-game 专用步骤 Variant、其余共享资源和各自玩法代码。按已授权范围做短增量。
- AC08／AC12：只修正 base 和 ui-game，保护 topdown 和已保存成品。正式项目中心普通 Save，保留现有版本和已有封存；不做追加 Bump、父同步、修改 ParentSnapshot 或框架发布。若景深/相机/渲染问题在框架有证据且确需扩大范围，交主对话确定。
- AC10／AC11：用户已认可其余五个子模板的页面效果，包括视觉小说原 UI + 玻璃 GM、source3d 原气泡；R3 已在做的技术复验继续完成。更新本次两个模板的真实截图，单独记录 R4 视觉评估和技术复验。对照图为 `evidence/i-r7/ui-game/previews/ui-game-play-1920x1080.png` 及 `evidence/acceptance-base/previews/`。
