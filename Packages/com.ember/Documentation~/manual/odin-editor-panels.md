# Odin 编辑工作区

当前图片入口统一为 `Ember/视觉小说/图片资源管理`，左侧分类包含角色立绘、场景背景和界面皮肤。
按用户最终选择移除独立“立绘管理”菜单与专用窗口；下方分离窗口的记录为历史验收，不代表当前入口。
统一入口调整已通过框架实例 Unity 编译及菜单核对，控制台无错误或警告；模板正式封存为 **0.17.3**。

本次调整使用 Odin 4.0.2 的菜单和编辑器绘制 API；保留既有 EditorWindow 生命周期、
SerializedObject、Undo、Prefab 记录与业务服务调用。专用数据表、预览场景和剧情 GraphView 继续使用原实现。

## 框架窗口

| 入口 | 工作方式 |
|---|---|
| TMPEx Inspector | Key 与文本优先；固定字体和跟随皮肤分开；跟随时逐皮肤选择字体，支持混合值多选。 |
| UI 开发中心 | 左侧切换创建、总览、模块模板与维护；总览用资产列表和单项详情，按 Prefab 路径保留选择。 |
| 项目中心 | 左侧工作区导航；初始化、模板开发和校验继续调用原面板；模板 AI Skill 保留独立入口。 |
| 多语言中心 | 源语言置顶、各语言独立编辑区；翻译助手折叠；保留 Key 搜索、缺译/复核筛选与草稿保存。 |
| 配置表中心 | 详情分为数据预览、配置与结构、诊断与产物、调用示例；校验/导出完成后切到结果页。 |
| 模板 AI Skill | 当前模板预览与更新为主要操作；包内只读浏览、技能源说明折叠，差异支持搜索。 |
| Scene UI 诊断 | Host 搜索、冻结快照和可滚动列表；默认展示活动数量，展开查看池、预热、投影与排序明细。 |
| 快速打开场景 | 主场景下拉单选，叠加场景多选；列表可滚动，打开按钮固定在列表之后。 |

固定字段宽度与专用绘制仍需在 Unity 中检查窄窗、浮动窗及停靠窗表现。此文说明源码中的设计，
不代表已经完成面板渲染或交互验收。

## 小说模板

小说窗口在当前项目 Assets 中开发，通过项目中心的正式保存和 Bump 流程交付。

- UI 皮肤编辑器：素材搜索；替换队列与显示效果分区；剧情关联在预览下方。
- Gameplay 主 UI 布局：位置尺寸、外观文字、仅预览图片分别折叠；外观字段按组件分区；保存按钮显示脏状态。
- 节点演出试播：人物初始状态按槽位分组，变量初值独立折叠；保留试播控制、独立场景和固定高度的状态区域。
- 二级步骤与预设：区分插入预设与包装已有范围，两种方式沿用原始命令复制和稳定 ID 处理。
- 引导编辑器：全局跳过条件与当前步骤分开；保留 ReorderableList、序列化属性和延后列表操作。
- 当前小说：展示当前新游戏入口，并按名称或剧情 ID 搜索项目小说；显式按钮设置入口，旧存档登记保持原行为。
- 剧情图：只调整右侧内容标题、运行观察、节点操作与校验结果；节点、连线、缩放及 GraphView 未改造。
