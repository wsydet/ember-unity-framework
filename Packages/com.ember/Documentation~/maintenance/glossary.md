# Ember 通用术语字典

用途：把对话里的简化用语映射为明确对象和操作。适用于所有模板及未部署模板的消费项目。先读本页，再按项目正式活动模板读取 `Assets/Game/Documentation/<template-id>/glossary.md`（存在时）；合法派生模板还应读父模板字典。具体项目可另建项目字典，不把产品名词写进公共定义。

用户当次明确说明优先于字典。术语只澄清含义，不自动授权提交、发布、Bump、部署或覆盖本地修改。遇到同词不同义，先用上下文和正式身份记录判定，仍不明确再询问。

## 框架、模板和版本

| 简化用语／别称 | 默认含义 | 核对方式与边界 |
|---|---|---|
| 框架、Ember | 通用能力包 `com.ember`，含运行时、编辑器工具与随包文档 | “框架工程/仓库”特指维护工程 ember-unity-framework；不把其中所有 Assets 都视作框架代码 |
| 框架层 | `Packages/com.ember` 的通用实现 | 不依赖具体 Game/Player/Windward 类型；可选业务不是框架必备 Manager |
| 框架版本、Ember版本 | 消费项目实际解析的 com.ember 包版本 | 读取 UPM 解析结果及 package.json；同版本号的未发布工作区可能不同，必要时补 tag/commit/来源。不是 Unity 版本 |
| 框架升级、更新框架 | 变更消费项目安装的 com.ember 依赖版本/来源 | 不等于重新部署模板，已复制到 Assets 的业务不会因此自动合并 |
| 框架发版、发布框架 | 校验并交付新的包/tag及相应发行记录 | 与修改、保存、提交、推送分别处理；未获发布授权不执行 |
| 模板、业务模板 | 由项目中心管理的业务代码、资源、配置和文档装配 | 通过正式 ID 确认；例如 base、platformer-2d。不是 UPM 包、Prefab 或 UI 页面模板的同义词 |
| base、基础模板 | 各玩法可继承的共用业务骨架 | 与框架公共能力不同；其内容是部署到 Assets 的业务接线 |
| 模板版本 | 某个模板 ID 的版本与封存内容基线 | 必须同时说 ID；平台模板版本和框架包版本是独立维度 |
| 当前模板、活动模板 | 框架开发端正式“正在编辑”模板；消费端正式“活动部署”模板 | 以项目中心身份记录为准，不看当前场景、残留文件或窗口选项猜测 |
| 模板保存、普通保存 | 将当前 Assets 维护源通过项目中心保存到模板管理内容 | 更新实时 contentHash，不等于 Bump、发布或升级消费项目 |
| Bump、模板升版、封存 | 项目中心显式递增模板版本并记录 versionedContentHash | 保存后尚有未封存差异时，不能只凭旧版本号声称内容一致 |
| 模板升级 | 将新模板内容与消费项目既有部署/本地修改合并 | 不等同于更新包；先核对模板旧基线、新基线和本地差异 |
| 部署、套模板 | 项目中心将选定模板装配到目标工程 | 可能影响现有 Assets，须按已授权范围执行；不是普通保存 |
| 父模板、父快照 | 正式继承关系及 ParentSnapshot~ 记录的父基线 | 不是复制文件夹的非正式关系；禁止手改快照/hash |
| 消费项目 | 安装框架、部署模板并开发具体游戏的工程 | 例如 Windward；不在 PackageCache 修改通用修复 |
| 当前实现、工作区版本 | 本地源码和未提交修改所构成的实际状态 | 不能仅以 package.json 的版本号宣称已发布或其他项目已接入 |
| 扩展、拓展、Ember 扩展 | 具有稳定 ID、版本/契约与兼容声明、显式依赖及正式启用配置的可组合框架能力或编辑器扩展 | 不是共同父模板、UPM 包或常驻 Manager/Module 的别名；工具、Skill、专属文档发现及执行均须满足正式模板/项目身份、版本/hash、启用和模块条件，未启用不开放 |
| 框架 Wiki、框架wiki、对照字典、术语对照 | 框架公共术语入口本页，以及由它链接的随包架构、API、维护和迁移文档 | 玩法术语仍查正式活动模板字典；公共 Wiki 可解释未启用能力，但阅读说明不表示扩展已启用、Skill 已安装或工具可执行 |
| 基线、已签收 | 明确日期/版本/内容/范围的已确认结果 | 只覆盖记录范围；键盘签收不自动包含手柄、构建或全路线 |

## 能力、生命周期和验证

| 简化用语 | 默认含义 |
|---|---|
| Manager | 框架必要全局基础设施，实现 IEmberManager；不因业务可选而临时裁掉 |
| Module、模块 | 可选组合业务，实现 IEmberModule；Global 常驻仍属于 Module |
| 页面、EUI | 通过 EUI 开发中心制作/生成并由 EUIManager 驱动的 UI；Binding/EmberManaged 块由工具维护 |
| Loading、遮幕 | “Loading页”是展示页面，“遮幕会话”是覆盖/保持/揭幕的所有权，“场景加载”是业务操作；三者不互为同义词 |
| 闭幕、覆盖 | 进入动画至覆盖终态；Covered 还需跨过实际渲染屏障 |
| 揭幕、开幕 | 业务许可后显露内容；RevealAsync 包含退出及页面清理 |
| 准备完成 | WhenPrepared 必要准备成功；须检查结果，不等于提交或可交互 |
| 提交完成、运行就绪 | WhenRunning 的进入/原位提交生命周期成功；不代表所有清理/表现已完成 |
| 整体完成 | 必须按对象说明：请求 Completion、会话 RevealFinished、WhenInteractive 不完全相同；外部持有遮幕时 Completion 可以先完成 |
| 原位恢复、同场景恢复 | RequestInPlace，不加载/卸载原关卡；具体恢复内容由业务定义 |
| 用户暂停 | 玩家主动暂停意图；不是所有 timeScale=0 的统称 |
| 内部暂停、事务暂停 | 业务为一致性交接取得的暂停句柄；不能反过来冻结自身正在等待的遮幕 |
| 会话、句柄、owner、代次 | 本次操作的所有权与有效性；旧释放/迟到回调不得影响新操作 |
| 重编译、编译通过 | 主动请求 Unity 编译并确认本次编译/域重载完成后读取 Console；刷新返回成功不等于编译通过 |
| MCP | Unity 操作桥接时指 Unity MCP；涉及其他服务须带服务名。Unity端包与运行中的服务端是不同安装对象 |
| 增量验证 | 仅运行新增或直接受影响的用例；不默认为全量测试 |
| 人工验收 | 用户或明确记录的人工输入现场；代码检查/自动测试不替代 |

## 维护约定

新简称按“用语、明确含义、来源、容易混淆的边界”补充。公共含义放本页；玩法术语放所属模板字典并通过正式模板保存分发；产品专属规则放消费项目。不要在词条里固化“最新版本号”，版本以当前工程证据为准。
