# 当前模板文档

这里随模板一起加载、保存和部署；修改前先在 `Ember/项目中心` 确认当前编辑模板。

- [基础模板文档](base/README.md)：基础业务骨架与可选模块。
- [视觉小说模板文档](visual-novel/README.md)：功能范围、剧情与存档设计、分阶段实施和验收。

派生模板在本目录下使用自己的模板 ID 建立专属子目录，并在本入口追加链接。
继承的 `base/` 文档保留；派生业务内容不反向写入基础模板。

文档在项目 Assets 中编辑，通过模板开发页保存并显式 Bump；不要直接编辑 Templates~ 或 ParentSnapshot~。
加载其他模板会替换本目录，未保存的文档也会被替换。框架公共 API 和发布文档不随模板切换。
