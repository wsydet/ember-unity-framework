## 完整示例：最后一盏灯

新游戏读取“当前小说”配置，模板初始选择《最后一盏灯》。2026-09-21 已改为与黄昏天台美术一致的原创短篇：林晚、周砚和“我”决定现在听完旧录音，或先写回信、约定下次见面。共 79 句，单路线 59 句、约 2,908 / 2,937 字（含标点），按 300 字/分钟估算约 10 分钟，非实测时长。

**从这里开始：[示例逐步体验与编写对照](SampleWalkthrough.md)。** 包含每个演出位置、操作检查、两条结局路线、配表键、旁白/内心写法与扩展方法。

流程：开场 → 玩家选择 → 听录音 / 写回信 → 共同收尾 → 条件分流 → 有人听见 / 明天继续。Chapter bool `heard` 仍由两条路线设为 true / false；所有原节点/选项/连接/结局稳定 ID 保留。已有台词 ID 保留并提升 textRevision，对话段 contentRevision 提升；旧版本 LastLight 存档可能因内容兼容检查而无法恢复，应从新游戏体验本次改稿，不删除用户存档、不绕过兼容检查。

旁白使用空角色键；内心独白使用角色 `lastlight_inner`（我（内心））及括号文字，这是现有 Say 的编写约定，不是新的指令类型。`lastlight_wan`（林晚）与 `lastlight_zhou`（周砚）使用独立角色表项，不重命名 M1 的 alice/lin。

示例包含居中立绘、左右双人、隐藏立绘后的纯背景旁白、等待、BGM/SFX、两句 Voice、选择、变量分流和双结局。图片位于 `UI/Module/Narrative/Atlas/LastLight`；BGM/SFX 仍复用 M1Sample，因此交付时保留两目录。Voice 是 Windows Huihui 合成语音，仅用于功能演示，不是真人录音；其余 77 句为空 Voice，正常逐字推进。跨章节示例继续参考 M1Sample；错误资源/断链等反例只在测试副本制造，不污染正式故事。

## 选择当前小说

打开 `Ember/视觉小说/当前小说`，在“快速选择”下拉中选择小说，或直接拖入 `NarrativeStorySO`。流程编辑器顶部也有“当前小说”和“设为新游戏入口”快捷按钮。选择立即保存到 `Config/Narrative/Library`，主菜单的新游戏与标题使用这一选择。新游戏显示阶段加载条与百分比，首个可读画面准备完成后再揭幕。

配置保存 Unity 资源引用，不依赖小说的目录或文件名。可在 Project 中重命名、移动小说资产（保留 `.meta` GUID）；章节与节点继续通过引用关联。配置中的已登记小说用于按稳定剧情 ID 恢复存档，切换入口不会把旧存档加载到新小说。不要更改现有剧情 ID，也不要删除仍有存档需要恢复的小说登记。旧版路径存档优先按其已有 StoryId 查找，未登记时仍尝试原 Resources 路径。

节点试播的画面区域与状态区分开布局，状态、警告和动作列表在固定高度滚动区显示，不再随指令切换挤压主视觉。

## 写一段剧情

1. 在 `Ember/视觉小说/流程编辑与运行观察` 选择 Story，进入章节，在画布空格菜单添加对话段。优先按场景变化、叙事段落和选择边界拆段，不必每句话创建节点。
2. 展开段内指令。Say 使用多行台词框；角色和资源保留文本键，同时可从已导出配表下拉选择。背景只列背景行，立绘只列立绘行，BGM/SFX/Voice 按类别筛选；Say 配音只列 Voice。未知键保留原值供修复，打开窗口不会自动替换。
3. 配表源文件位于 `Assets/GameResource/TableSources/`，通过现有配表流程烘焙导出，再点击流程窗口“校验剧情”重新读取。不要改生成 bytes。资源路径为 Resources 相对路径，不带扩展名；图片须导入为 Sprite，音频须能加载为 AudioClip。
4. 用 ↑ / ↓ 排序，复制产生新的 commandId / lineId / optionId。Ctrl+D 复制一组节点时生成新稳定 ID，并重映射组内连接。移动和重排不应改写原有 ID。改写台词时调整台词修订，以免将新文案视为旧的已读句。
5. 创建选择 SO 并连接各选项；条件分流按顺序首个命中，兜底必填。变量先在章节或剧情中声明，再在赋值和条件中明确选择 Chapter / Global。跨章只通过章节出口和 Story 路线连接。
6. “校验剧情”检查全部章节、连接、变量和键，并补查引用的 Sprite/AudioClip 是否存在且类型正确。静态检查不能替代 Player 中的资源提供器与加载失败验收。点击错误定位会进入对应章节、选中节点并展开对应指令/选项；无法唯一定位时保留错误 ID，不跳到无关节点。

## 从指定入口试播

先从 `Assets/Game/Scenes/FrameworkScene.unity` 运行到主菜单，在 Project 中选择 Story、Chapter 或一个已登记节点，再使用 `Ember/视觉小说/从所选入口开始新游戏（Play 主菜单）`。

这会经正式 Loading 流程建立新会话：Story 使用默认入口，Chapter 从章节入口开始，节点从该节点的第一条指令开始。全局与局部变量采用定义默认值；不会补跑此前的变量赋值、背景、BGM、配音或其他副作用。需要前置演出的段落应从包含准备指令的节点开始，或完整走前面的流程。它不是存档恢复或运行中跳转，不修改 SO 的默认入口。

已有小说会话时该菜单不可用，先返回主菜单。此试播仍使用当前项目的账号偏好、已读和自动存档机制；需要保留测试前自动槽时先备份 `Application.persistentDataPath/VisualNovelSaves`。不自动清空存档，也不覆盖手动槽。新示例使用独立 storyId，原 M1 存档仍指向原 StoryPath，不改写其内容。

运行观察窗口只观察：可以中途打开、重开、开关跟随和定位错误，不承担试播会话的生命周期。定位当前与运行错误按运行快照的 storyId / chapterId 查找，浏览其他剧情不会改变运行定位范围；关闭跟随时，其他剧情中相同章节/节点 ID 不应被误高亮。无法唯一定位时保留诊断 ID 和提示。退出 Gameplay 或 Play Mode 后应清除旧观察源。编辑器菜单同时服从 NarrativeModule.Enabled 与当前 visual-novel 模板身份。跨剧情定位用例已在用户提供的 XML 中通过；本批最后两项测试修正后用户确认全部通过，未取得新的全量 XML。

## E0：透明度动作与等待

本批仅交付执行基础和实际透明度动作，不包含位移、震屏、遮罩绘制、效果播放或镜头。`NovelTargetKind` 为 Stage、Background、Character、Mask、Effect 定义身份类型；E0 只接受前三类，后两类明确校验失败，留待后续批次创建目标。舞台指背景和人物，不含对白/阅读工具。

### 编排步骤

1. 用 Character / Show 显示人物，填写唯一实例 ID，例如 `alice-main` 和 `alice-memory`。这两个实例可以使用同一角色的相同或不同立绘资源。左/中/右是摆放位置，不是实例身份；显式 ID 的 Show 遇到已占用槽位报错，不能静默丢失人物。
2. Replace / Hide 填原实例 ID，按身份作用于该人物，忽略位置字段。E0 禁止通过再次 Show 把已有实例挪到别处；移动留 E1。空 ID 的旧命令沿用槽位语义（内部身份 `legacy-Left/Center/Right`），原枚举值 0–7 不变；新增 Opacity=8、WaitActions=9。
3. 添加“透明度动作”：Stage/Background 不必填写人物 ID；Character 必须填写已显示的实例 ID。填写动作 ID、最终透明度 0–1、非负有限时长与开始延迟。不勾“并行启动”会等待自身结束；勾选后立即继续后续指令，动作可与另一目标的动作、对白或纯 Wait 同时推进。
4. 添加“等待动作组”，列出一个或多个已启动动作 ID，全部完成或取消后继续。等待绑定当时的句柄，不会被后续同名实例替换误导。尚未执行分支中的动作 ID 会报定位错误，不无限等待。动作 ID 在章节内唯一；循环再次执行已结束的 ID 会获得新句柄；同名活动动作报错。单会话最多保留 4096 个命名结果。
5. 同目标同属性由新动作立即接管，即使新动作有开始延迟；旧句柄转 Cancelled，不再写值。新动作保存接管时当前值，延迟后从该值继续。等待旧动作会解除；要等最终动作，应将新 ID 加入等待列表。同一节点中可见的潜在接管会显示警告；跨分支真实目标与句柄状态由运行时检查。

每个句柄包含会话代次、序号、动作 ID、目标类型/实例、属性名、进度和 Running/Completed/Cancelled 状态。E0 批次交付的可编排属性是 Opacity；Stage 与人物透明度独立计算并叠乘。执行器由现有会话 Tick 驱动，不新建全局 Manager、异步回调链或第二套音频系统。流程窗口“运行观察”显示活动动作、目标、进度与等待句柄。

### 暂停、阅读与存档

- 历史、设置、菜单、Loading、手动隐藏等继续使用原会话暂停门控；延迟与动作一起冻结。阅读倍率影响动作、原图像过渡和纯 Wait；配音音高与 BGM/SFX 规则不变。
- 已读快进把有限动作收敛到终值，并在未读句/选项前保持正确舞台。结束、失败、换会话、返回菜单和退出取消旧任务；执行器没有可晚到的动作回调。纯 Wait 仍是计时等待，不改为动作等待。
- Schema 2 仍只在完整对白或选项稳定点保存；活动动作以目标值写入副本，不瞬间改变当前屏幕。Cancelled 保持取消，活动句柄的恢复结果记为 Completed，因此稳定点后的 WaitActions 能继续，不重播过渡。
- Schema 1 旧档迁移为默认透明度 1、默认缩放/旋转/偏移、槽位派生身份与空动作/效果列表。无 E0 数据的旧剧情保持原语义指纹；添加/改变 E0 编排会按既有规则拒绝不兼容旧档。未知 schema、非法实例/槽位/透明度或本批不支持的非默认变换/非空效果列表明确拒绝。
- 恢复继续走候选准备、Loading 遮挡、提交和揭幕，不重播 Voice/SFX，不重复历史或重置账号已读。E0 不恢复过渡帧/粒子相位，也不实现任意时刻存档。

## E1：人物移动与强调

本节描述 Assets 中的 E1 实现。本轮测试已获用户确认全部通过，不代表已封版模板能力。已封版仍为 visual-novel 0.5.0 / preview，父模板 base 0.6.4。

- Character 的显式 InstanceId 不随位置变化；Move 支持 Named 左/中/右与 Normalized 坐标。坐标是现有立绘根节点锚点中心在父舞台中的归一化位置，允许 -2–3 以编排画面外进出场。最多三个在场实例。
- 命名目标在动作开始时预占，冲突报错。双人交换先将一人移至 Normalized 临时位置，再依次移动。移动途中 Replace 按实例换表情，保留位移动作。
- Move、Scale、Rotate、Opacity 可分别并行；同实例同属性接管。Duration、Delay、Parallel、ActionId 与 WaitActions 沿用 E0；E1 提供 Linear / SmoothStep / EaseIn / EaseOut。Opacity 仍保持线性。
- Mirror、Layer 为即时属性，可设置延迟但时长必须为 0。Gesture 的 Jump / Nod 叠加临时姿态，结束或取消恢复基准。ExitAfterMove 要求画面外坐标，完成后移除实例。
- Emphasis 默认 Off；Auto 按人物配表 CharacterId 匹配对白角色，旁白或无对应在场人物时全亮；Manual 指定实例，其余亮度由 DimFactor 控制。
- Schema 3 保存最终位移、缩放、旋转、镜像、层级及强调模式，动作中的稳定点保存投影到终态，临时手势不保存；接受 Schema 1/2 的兼容默认值。旧剧情指纹不因 E1 默认字段变化而改变。

E1 演出已融入《最后一盏灯》原正文，与 E0 共用正式素材；无独立 E1 生成入口。请参照 [示例体验与仿写](SampleWalkthrough.md)，从新游戏开始阅读。

## 单节点编辑态演出试播

工作区新增入口：选中对话节点 → “播放节点”。操作与起始状态设置见 [README](README.md#编辑态节点演出试播)。这与原静态“预览节点”及 Play Mode 运行观察是三个独立入口；试播不注册全局 NarrativeObservation，也不改变主 UI 布局草稿。

自动对白默认开启，点击画面或“推进”会切换为手动推进：第一次补全正文，再次进入下一句。暂停/继续与阅读倍率沿用会话规则，音频不随倍率变调。底板、立绘、人物移动/强调、并行动作、等待、震动、闪白和双图渐变均调用正式舞台实现；正文与分页经正式文字接口显示，不接正式存档/菜单回调。

“停止”后可设置背景资源键、最多三个起始人物及变量。实例 ID 必须与 Move/Hide/CrossFade 等指令一致；不自动补建不存在的人物。缺少资源、前置动作或变量时显示具体错误，不能把失败作为正常完成。单节点只执行副本中的命令，不会沿 Next 跳转；末尾合成等待组只存在于临时副本。

试播音频使用独立 AudioSource / PlayableGraph，通过 INovelAudio 接入，不调用全局 AudioUtil 停止其他编辑器预览，也不调用 EmberAudioManager。播放、暂停和销毁基于 [Unity PlayableGraph API](https://docs.unity3d.com/cn/6000.0/ScriptReference/Playables.PlayableGraph.html)，音频输出接口见 [Unity AudioPlayableOutput](https://docs.unity3d.com/cn/6000.0/ScriptReference/Audio.AudioPlayableOutput.html)。本批测试修复后用户已确认“通过”，证据与边界见 [编辑工具收束记录](Implementation.md#编辑工具测试通过与文档收束)；实际听音不以状态测试替代。

## E3：粒子与声音编排

1. 粒子键是 `Resources/Effects/Narrative/<键>.prefab` 中的文件名，不带路径或扩展名，不建立新配表。首批是根节点单个 Local ParticleSystem，使用归一化 XY 单位；支持简单有色矩形粒子。纹理图集、原生粒子材质、3D 网格、拖尾、子发射器、碰撞、脚本与自带音源不在本批契约内。正式阅读页将粒子数据绘制到既有 EUI 背景 Item 的运行副本，避免 ScreenSpaceOverlay 看不到原生 Renderer；不需要另建 Canvas/Camera/Manager。
2. “播放粒子效果”：填资源键、独立实例 ID、归一化位置、缩放、同绑定层级。绑定人物填其既有实例 ID；留空绑定舞台。持续效果勾选 Persistent，结束用 EffectStop；一次性以粒子自然结束回收。创建/停止不阻塞等待，时长与延迟必须为 0。
3. 环境音选 SFX 表项，给每个循环独立实例 ID；AmbientVolume 调整剧情音量，AmbientStop 可淡出。BGM Play 在有旧音乐时做双轨交叉渐变，没有旧轨时淡入；BGMStop 淡出。音量始终与玩家的 BGM/SFX 偏好叠乘，Voice 规则不变。
4. 渐变可并行；ActionId 留空时使用 CommandId，可由 WaitActions 等待。等待的是有限包络，不是循环播放生命期。相同音轨由新渐变接管；最多保留当前/退出两轨，旧动作取消后解除等待。
5. Background Show/Replace/Hide 与章节切换清理未勾保留的效果/环境音；CrossFade 用于同场景表情/光照变化，不触发换场清理。BGM 跨场保留至停止/退出。人物隐藏/退场时其绑定粒子总会释放，即使勾了换场保留。
6. “播放节点”使用同一会话和效果实现；尾部只等本节点有限动作。持续粒子/循环音可继续显示至停止或关窗。重播先释放旧会话，重编译与进入 Play Mode 沿已有窗口关闭流程释放。

导入与验证：首次编译加载 `NarrativeE3Assets` 后自动创建三个缺失的粒子 Prefab，并由配表中心导出新音频键；随后用户已反馈“全部成功”，E3 按用户验收通过收束。导入失败会给出 `Narrative.E3` 诊断，修正后重新编译触发。不得手改生成 bytes；自定义粒子同名资源不会被覆盖。没有为演出添加测试段落或按钮。


## E4：文字节奏、分页与对白模式

“对白 / 旁白”的显示方式选择普通对白、居中标题 / 章节卡或全屏旁白。展开“结构化文字节奏”，按从小到大的 At 添加 Pause、Speed、Instant。At 按正文 Unicode 标量计数（0 起，含标点/换行）；详情见 [配置手册](EffectConfiguration.md#21-文字节奏与显示方式e4)。节奏只放数组，正文保持纯文本。修改文字后核对偏移，修改节奏/模式会改变存档语义指纹；不会自动改变台词修订或已读身份。

长文自动分页。手动推进先补全当前页、再翻页，末页完成后再进入下一句。只有整句完成才写完整历史和已读标记、开放稳定点；中间翻页不会切断或重放 Voice。自动中间页等待阅读间隔，末页等待配音；仅已读快进可以跨过整句所有页。字号改变重新排版；存档恢复完整末页，不重放句内事件。

无对白演出使用“剧情对白显隐 → 不显示”，随后编排已有演出与 Wait / WaitActions；下一句、选项或结束自动恢复，也可显式显示。不要用玩家隐藏功能代替剧情隐藏：玩家隐藏会暂停。

“播放节点”使用正式文字控件与同一会话规则，可以检查逐页推进、停顿、切模式、自动/手动和暂停倍率。静态布局预览仍用于普通基础布局，新模式请进入试播查看。停止、关窗与重编译沿已有释放链路；不写账户或存档。

E4 测试已获用户独立确认通过，文档已收束；未提供 XML 或复跑计数，多字号/分辨率和平台观感不扩大推定。

## 二级步骤与章节卡（0.8.0）

在剧情节点中选择「插入二级步骤 / 自定义步骤…」。内置进场、受击、回忆氛围、镜头/遮罩复位、隐藏所有立绘、恢复舞台状态、场景收尾。组合以自定义颜色显示，可折叠、复制、解包或删除；展开后仍能逐条调整原有基础指令。窗口的范围编号从 1 开始，可将连续步骤原位包装，也可保存为项目内复用的 `NarrativeStepPresetSO`。

自定义步骤资产建议放在 `Assets/GameResource/Authoring/Narrative/StepPresets`。插入为独立副本：后续修改预设不会修改已经插入的剧情。命令、台词、动作 ID 会重新生成，内部等待同步重映射；包含组合外等待的范围不能直接复制，需把启动动作一起选入。人物实例、变量、资源键保持原值，复用到其他角色时需要调整。

「隐藏所有立绘」包含已移动到自由位置的人物，并释放人物动作与绑定效果，可调整淡出时长和缓动。「恢复舞台状态」恢复镜头、遮罩、舞台透明度、强调和对话可见性；「场景收尾」先隐藏立绘再恢复这些状态。二者不清空剧情变量、不停止音乐或全部粒子，按需要追加对应基础步骤。

Say 步骤可设置默认/打字机/渐显/立即显示、文字渐显时长、打字机速度倍率、文字缓动；章节卡额外设置点击退出渐隐时长。默认章节卡文字渐显，其他文本为打字机。文字未完成时点击先补全，之后点击使章节卡整体淡出，完成后才进入下一步；时长设 0 可立即退出。暂停会冻结过渡，已读快进会收束过渡。

LastLight 的四个参考对话段展示舞台复位、隐藏所有立绘、环境音效和回忆氛围分组；其台词、说话人、选项与分支保持原样。自定义预设目录提供可直接插入的通用样例。
