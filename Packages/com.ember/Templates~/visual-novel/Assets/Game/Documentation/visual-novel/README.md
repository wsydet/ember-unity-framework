## 启动与操作

打开 `Assets/Game/Scenes/FrameworkScene.unity`，进入 Play Mode，从主菜单选择“新游戏”。默认读取 `Config/Narrative/LastLight/Story`。编辑器测试键盘时，先点击 Game 视图获得焦点；流程编辑器中的空格用于节点搜索，不推进游戏。

| 操作 | 入口与行为 |
|---|---|
| 手动推进 | 点击底部半透明渐变区域（包括正文与箭头位置），或按 Space / Enter；逐字显示中先补全文字，再次输入推进 |
| 选择 | 点击对应选项；推进区域不能代替选项选择 |
| 阅读工具 | 左上字号、历史、隐藏；右上自动与 1X / 2X / 3X 倍率；右下打开阅读菜单 |
| 阅读菜单 | 存档/读档、快速保存、快速读取、系统设置、仅已读快进、返回主菜单 |
| 快捷键 | A 切换自动，左 Ctrl 按住已读快进，H 打开历史，F5 快存，F9 快读，鼠标右键隐藏/恢复，Esc 返回菜单 |
| 隐藏与恢复 | 保留背景和立绘；首次点击或推进输入只恢复 UI，不跳句 |

弹窗和 Loading 沿用会话暂停门控；历史、设置、菜单及嵌套存档未关闭时，不推进底层对白。自动等待文字与 Voice 完成；倍率不改变配音音高、BGM/SFX 或全局时间。快进停在未读对白和选项。

历史只读，最多 200 条已完整显示的对白，不回滚、不重播。当前采用全屏暗化舞台、灰色姓名与白色正文两列、黄色最新记录标记和右侧滚动条；长文本换行仍对齐正文列。短历史居中，长历史打开时滚至最新记录。

`Ember / 视觉小说 / Gameplay 主UI布局` 编辑正式阅读页、阅读菜单、字号设置及历史记录弹窗，不包含启动主菜单。可拖动选框或调整锚点、位置、实际宽高与缩放，支持撤销、预设/自定义分辨率及剧情节点预览。节点预览只计算当前节点，不推断前置分支，也不执行剧情、音频或存档。

点击“保存布局与外观”写入正式阅读页、阅读菜单、字号设置和历史记录 Prefab；预览示例图片/文字不写入剧情。保存前会备份 Prefab/meta 到 `.utmp/visual-novel-ui-layout/`。外部修改导致依赖变化时需重新载入，不能用旧草稿覆盖。宽高字段以当前预览分辨率的画布单位显示，拉伸锚点继续参与分辨率适配。

布局窗口现增加“对话底板 / 渐变”“选项样式”“阅读菜单外观”，右侧“子元素”可选择底板、箭头、图标、文字和分割线。图片可修改 Sprite、颜色/透明度、图片模式、保持比例与九宫格参数；文字可修改字体、基础字号、颜色、对齐、字距、行距与边距；按钮可修改颜色或图片状态，现有渐变组件可编辑开关与颜色。选项样式作用于阅读页内嵌模板，预览实例继承样式。

替换底部图片：选择“对话底板 / 渐变”，再选择 BottomSolid 或 BottomFade 等子元素修改图片与颜色；替换箭头则选择“推进按钮”的图像子元素。Advance 整体是透明命中层，换图不会自动调整点击范围；Alpha 为 0 时面板会提示。可勾选“显示推进点击范围”检查范围。图片最终颜色会与已有渐变及按钮状态颜色叠乘。

“保存布局与外观”统一保存草稿；样式支持撤销/重做、重载恢复与嵌套 Prefab 覆盖记录。“还原此元素到已保存状态”还原当前子元素自己的布局与样式，不递归清除其他元素。背景、立绘和对白示例仍只用于预览，正式内容由剧情控制；正文基础字号运行时叠加玩家字号偏好。当前没有主题预设或任意组件/绑定编辑入口。

底部渐变采用黑色托底和向上透明过渡。正文右边界留在可见推进箭头之前；**Advance 的点击范围覆盖整片底部渐变，不能按箭头图标尺寸缩小点击范围**。阅读菜单压缩上下留白，分割线仅保留在相邻菜单项之间，末项下方不画线。

新增 Page / Popup / Item、骨架、Binding 和注册必须经 EUI 开发中心；已有 Binding 调整后使用统一生成器。正式资源位于 `Resources/UI/Module/Narrative/Prefabs`，8 张通用图标位于 `Resources/UI/Common/Atlas/Novel`。

## 编辑态节点演出试播

在“流程编辑与运行观察”选中一个对话节点，点击右侧工具栏“播放节点”，打开可停靠的“节点演出试播”窗口。不进入 Play Mode。原“预览节点”仍是静态布局预览，两者独立。

试播复用 NovelSession 和正式阅读页的 E0–E4 舞台与文字接口，支持自动对白、推进、暂停/继续、从头重播、停止、1X/2X/3X、静音、指令定位与动作进度。暂停冻结对白和演出；静音只改变音量，保留配音等待。只执行选中对话节点，节点末尾会等待本节点剩余有限动作结束，保留最后画面；持续粒子与环境循环音不加入末尾等待；有限音量渐变参与等待。节点结束保留持续演出，直到显式停止、重播或关窗清理。

默认空舞台开始。如节点依赖前置人物，先停止，在“起始设置”启用指定起始画面，选择背景、人物资源键，填写与节点指令一致的实例 ID，可指定左/中/右或归一化位置。变量初值来自当前章节/剧情，可在窗口内覆盖；不写回 SO。没有前置状态推断。缺少目标或资源会显示原指令诊断。

窗口使用已保存的正式阅读页 Prefab，布局窗口未保存草稿不参与试播。节点编辑不改变已启动的指令副本；项目资源改变会暂停并提示重播。停止恢复起始画面；关窗、重编译、进入 Play Mode 或禁用模板入口会清理会话、音频与预览场景。此窗口不操作正式存档、已读记录、全局音频管理器或运行观察源。

本批测试修复后已获用户确认“通过”；未提供修复后 XML、复跑范围与总数，不登记为代理自动验证或 482/482。编辑态实际听音、完整交互及两种分辨率观感仍需单独验收。跨节点/选项分支连续播放、时间轴拖动和倒放不属于首批。

主菜单为新游戏、继续游戏、读取存档、设置、退出；无对应存档时隐藏继续/读取。继续加载最近成功保存进度，读取先打开槽位页。6 个手动槽、1 个快速槽、1 个自动槽；完整对白或选项就绪时才可保存。文件位于 `Application.persistentDataPath/VisualNovelSaves`。

读档复用 Loading，在首屏准备完成后揭幕；不重播配音、不重复历史、不回退账号已读。坏档/不兼容会提示，不静默回退到其他存档。

背景、人物、表情与音频通过源表和 SO 资源键接入，不手改生成 bytes。LastLight 有两句合成 Voice 用于功能演示；正式产品录音沿用相同接入流程。音频复用 EmberAudioManager，NovelAudio 只管理当前会话句柄。
