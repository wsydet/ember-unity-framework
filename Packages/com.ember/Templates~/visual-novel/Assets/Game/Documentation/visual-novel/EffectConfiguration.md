# 剧情效果配置手册

适用范围：工作区 E0–E5。E5 镜头、背景擦除及演出预设已获用户确认全部通过、文档已收束。E4 测试已获用户确认通过、文档已收束；未提供 XML/复跑总数，画面与平台验收不扩大推定。E0–E2 测试已获用户确认；E3 已获用户“全部成功”反馈并收束，未提供自动测试 XML/总数，平台与逐项观感不扩大推定。本批汇总纳入 0.6.0 收尾封存。更新于 2026-09-22。本次基础框架收尾版本为 0.6.0 / preview，当前工作区与封版状态请看 [Implementation](Implementation.md)。本文按实际编辑器字段和运行代码编写，不将规划中的效果列为已支持。

## 1. 先分清两种配置

- **对白步骤内**：决定“谁说、说什么、播放哪句配音”。
- **独立演出步骤**：决定“人物在哪里、怎么动、背景怎么变、什么时候等待”。放在对白之前，或勾选并行后与后面的对白同时运行。

两者实际都在同一个对话节点的“段内步骤”列表里，从上往下执行。这里的“步骤外”指独立于 Say 的演出指令，不是另一个隐藏配置面板。

入口：`Ember → 视觉小说 → 流程编辑与运行观察`，选择对话节点，在“对话内容”的段内步骤中点“+ 新指令”，通过“这一步做什么”选择类型。也可在对话 SO 的 Inspector 中编辑。

**说话角色不会自动决定立绘位置。** 要让林晚在左边说话，先用“立绘 → 显示”把实例放到左侧，再添加林晚的对白；她之后移动到右侧，后面的对白仍填写同一个角色键。

## 2. 对白步骤内能配置什么

选择“对白 / 旁白”。

| 编辑器字段 | 填什么 | 结果 |
|---|---|---|
| 角色键（留空为旁白） | 角色表中的键，例如 `lastlight_wan` | 显示角色姓名；留空显示旁白，不自动创建或移动人物 |
| 说话人称呼 Key（留空用角色名） | 内容文案表里的称呼 Key，例如 `speaker.unknown` | 本句姓名框改为该 Key 的译文（如 `？？？`）；留空或查不到都按角色名显示，见第 10 节 |
| 台词 | 纯文本正文，不可为空，不嵌节奏控制标记 | 首次推进补全当前页，再推进翻页；末页完成后推进下一句 |
| 多语言 Key（留空用上面的台词） | 内容文案表里的稳定 Key | 运行时按当前语言取译文；下一行逐语言预览，见第 10 节 |
| 显示方式 | 普通对白 / 居中标题 / 全屏旁白 | 本句独立选择；居中标题使用不透明全屏底色、中央大字，整屏点击推进；后续普通对白还原原布局 |
| 结构化文字节奏 | 按 At 递增的列表，详见下节 | 配置停顿、速度与即时片段，不改正文或历史 |
| 配音键（可留空） | 音频表中类别为 Voice 的键 | 随本句播放；自动阅读等待文字与配音完成；留空不播放 |
| 标识与修订 → 指令 ID | 编辑器创建的稳定标识 | 定位这一条指令，不能与本章节其他指令重复 |
| 标识与修订 → 台词 ID | 本句稳定标识 | 用于已读、历史和存档定位，不与其他台词重复 |
| 标识与修订 → 台词修订 | 从 1 开始的整数 | 改写台词后提高修订，避免把新内容当成旧的已读内容 |

### 2.1 文字节奏与显示方式（E4）

Say 的正文始终是纯文本。节奏数组每项有以下字段；没有数组时沿用全局文字速度。

| 字段 | 范围与含义 |
|---|---|
| At | 从 0 起，显示第几个 Unicode 标量之前生效，必须在正文内且严格递增；标点和换行计数，代理对表示的一个字符计 1 |
| Pause | 在该位置先等待 0–60 秒；受暂停和阅读倍率控制 |
| Speed | 从该位置起至下一节奏项的文字速度倍率，0.05–20；默认 1，与玩家文字速度及 1X/2X/3X 叠乘 |
| Instant | 停顿后立即显示的标量数，默认 0，不得超出正文；跨页片段仍等待翻页，不会自动跨越页门控 |

例如 `天台的门在身后合上。雨后的栏杆…`，At=10、Pause=0.65、Speed=0.7、Instant=0 表示第一句句号后稍停，再慢速继续。若只需在某片段变速，片段结束处再加 Speed=1 的项；不要向正文写 `<wait>`、`<speed>` 等标记。改正文长度后须重新核对 At。普通尖括号和反斜杠按字面显示；本批不提供正文富文本样式脚本。

三种模式均复用当前阅读页：普通对白保留作者在 UI 中心配置的布局；标题居中，不显示姓名；全屏旁白使用安全区内的较大文字区，不显示姓名。后两种使用暗色底板，下一句普通对白恢复原锚点、对齐、底板和姓名分隔线。没有创建第二套 UI 或独立 Manager。

**分页与推进**：按实际 TMP 排版、当前字号与文字区域分页。首次推进补全本页并跳过剩余句内停顿；本页已完整时再推进翻页；最后一页完整后再推进下一句。同帧输入合并。中间页仍属 Revealing，不写历史、不标记已读、不开放存档。自动模式逐页等待 `max(0.5, 本页字数 / 20) + 玩家间隔`（再除阅读倍率）；配音跨页连续播放，末页沿用配音结束后等待间隔的规则。已读快进跳过整句停顿和所有页，在未读句前停下。

**字号与恢复**：更改字号/区域后从当前页起点重排，不重新播放已触发节奏。整句历史始终保留完整原文，只追加一次。稳定点存档恢复到按当前字号排出的末页并完整显示，不重放停顿、即时片段或配音；页码和句内计时不写入 Schema 5。模式和节奏变更参与语义校验，旧内容档可能被判为不兼容，原文件保留。

### 位置、表情和强调放哪里？

| 想配置的内容 | 当前应该用什么 |
|---|---|
| 说话人的立绘在左 / 中 / 右 | “立绘”显示时设置画面位置；已有实例用“人物移动” |
| 同一个人从左走到右 | 独立的“人物移动”，填写实例 ID |
| 切换表情图片 | 即时/旧式过渡用“立绘 → 替换”；双图过渡用“图片交叉淡化”，目标 Character、相同实例 ID 和新表情资源键 |
| 说话者更亮、其他人变暗 | 独立“角色强调 → Auto”；之后随每句角色键变化 |
| 这句只强调指定人物 | 对白前放“角色强调 → Manual”，指定实例；之后显式改回 Auto 或 Off |
| 姓名文字的位置、对话框位置 | 正式阅读页布局；当前没有逐句位置覆盖参数 |
| 单句逐字速度、句中暂停、对白模式 | 使用本句“结构化文字节奏”和“显示方式” |
| 单句专用字体/颜色 | 尚无逐句覆盖参数，继续使用正式 UI 外观与玩家字号设置 |

角色键、立绘资源键与实例 ID 各有用途：

| 名称 | 林晚示例 | 用途 |
|---|---|---|
| 角色键 | `lastlight_wan` | 姓名、对白身份、自动强调匹配 |
| 立绘资源键 | `lastlight_alice` | 找到图片；这是沿用的历史键名，实际为正式林晚立绘 |
| 实例 ID | `wan` | 找到当前画面中的这个人物，供移动、透明度、替换和隐藏使用 |
| 动作 ID | `wan_walk_left`（可留空） | 可选的等待句柄别名：找到某次动作，供等待组使用，不是人物身份；留空时该动作的句柄就是本步骤 ID |
| 说话人称呼 Key | `speaker.unknown`（可留空） | 只临时代替**姓名框显示**（揭晓前显示 `？？？`）；不改变对白身份、不参与强调匹配、不进存档指纹 |

同一角色若同时显示两份，使用不同实例 ID。Auto 会强调所有匹配该角色的在场实例；需要只强调其中一份时用 Manual。

## 3. 独立演出步骤总表

### 3.1 显示、替换和隐藏

| “这一步做什么” | 可配置项 | 实际行为与限制 |
|---|---|---|
| 立绘 → 显示 Show | 实例 ID、命名位置 / 归一化入场位置、图片资源键、过渡秒数 | 创建人物实例，支持淡入；最多三个在场实例；归一化入场必须填写实例 ID |
| 立绘 → 替换 Replace | 原实例 ID、新图片资源键、过渡秒数 | 按身份替换；显式实例替换保留位置和变换，可在移动中换图；不是新旧双图交叉淡化 |
| 立绘 → 隐藏 Hide | 原实例 ID、过渡秒数 | 隐藏并移除人物；不需要资源键。旧剧情留空 ID 按命名位置操作 |
| 背景 → 显示 / 替换 | 背景资源键、过渡秒数 | 使用配表图片并执行透明度过渡；不是双图交叉淡化 |
| 背景 → 隐藏 | 过渡秒数 | 移除背景，不需要资源键 |

这些基础显示步骤没有 Parallel、ActionId 或开始延迟字段。需要“边淡出边说话”，先显示人物，再编排并行的“透明度动作”；最后需要移除实例时再 Hide。

新编排建议始终填写明确实例 ID。显式 Show 不用于挪动已有实例；移动到已占用命名位置会报冲突。同一实例 Show / Hide 会取消其旧动作，Replace 接管其透明度和进行中的 CrossFade，保留位移等其他属性动作。

### 3.2 人物动作与透明度

| 独立步骤 | 主要参数 | 用途 / 注意 |
|---|---|---|
| 人物移动 Move | 实例 ID、Named / Normalized、目标位置、完成后退场 | 左中右移动、坐标移动、画面外进出场；目标是已显示的人物 |
| 人物缩放 Scale | 最终 X/Y 缩放 | `(1,1)` 为原始大小；可分别缩放两轴，通常等比更自然 |
| 人物旋转 Rotate | 最终角度 | 围绕立绘根节点旋转；`0` 回正，值为目标角度，不是“再转多少度” |
| 人物镜像 Mirror | 水平镜像开关 | 水平翻转；时长必须为 0，可设置开始延迟 |
| 人物层级 Layer | -100～100 | 数值大的人物在前，小的在后；只改变人物之间的顺序，不越过阅读 UI |
| 跳动 / 点头 Gesture | Jump / Nod、强度、时长 | 在当前姿态上叠加临时动作，结束/取消恢复基准；不会永久改变 Move 或 Rotate 的目标 |
| 透明度动作 Opacity | Stage / Background / Character、最终透明度 | `0` 全透明、`1` 不透明；人物需实例 ID，舞台与背景不用填实例 ID |

透明度目标的区别：

- **Character**：只影响指定人物。变为 0 后实例仍存在、仍占命名位置，需要释放时再 Hide。
- **Background**：只影响当前背景，背景必须已显示。
- **Stage**：影响背景与所有人物，不影响对白、姓名和阅读按钮。最终显示透明度为舞台值与局部值相乘。

将 Stage 透明度降低是让舞台内容透明，露出后方已有画面，**不能据此配置黑幕、白幕或闪白**；透明度也不是亮度。角色强调调整的是人物亮度，不会让人变透明。

### 3.3 角色强调

| 模式 | 参数 | 行为 |
|---|---|---|
| Off | 无需目标 | 关闭强调，人物恢复原亮度；兼容默认值 |
| Auto | 其他人物亮度 DimFactor | 按当前 Say 的角色键和立绘表 CharacterId 匹配；旁白或说话者不在场时全部恢复亮度 |
| Manual | 指定实例 ID、DimFactor | 只强调该实例，其他在场人物变暗；目标必须存在 |

DimFactor 在 `0～1`，默认 `0.55`，越小越暗。模式持续生效，直到下一条 Emphasis 改变；不是只对紧跟着的一句话生效。当前强调是即时切换，没有渐变时长或并行动作句柄。

### 3.4 声音、等待和剧情控制

| 独立步骤 | 配置 | 行为 |
|---|---|---|
| 背景音乐 BGM | BGM 类资源键、剧情音量、渐变时长/延迟、并行/动作 ID | 无旧轨时淡入，有旧轨时交叉渐变；停止用 BGMStop，详见 E3 小节 |
| 音效 SFX | SFX 类资源键 | 播放一次短音效，不等待音效结束；它不是视觉特效 |
| 独立配音 Voice | Voice 类资源键 | 播放配音并等待完成后继续；有台词的配音通常直接配置在 Say 内 |
| 等待 Wait | 等待秒数 | 暂停剧情推进这段时间；已经启动的并行动作继续运行 |
| 等待动作组 WaitActions | 动作句柄列表 | 等指定动作全部完成或取消；句柄优先取“动作 ID”，动作 ID 留空时取该步骤的指令 ID；不是固定等待几秒 |
| 设置变量 SetVariable | 本章节 / 全局、变量 ID、值 | 给已声明变量赋值，供选择和分支条件使用；本身无视觉效果 |

选项、条件分流、章节连接在对应的节点/剧情配置中维护，不属于本表中的人物动作。

### 3.5 震动、遮罩与交叉淡化（E2）

在“这一步做什么”中选以下四种独立指令。都支持动作 ID、时长、开始延迟、并行和 WaitActions；**Cover/Flash 的总时长 = 动作秒数 + 保持秒数**，延迟另计。

| 指令 | 参数与范围 | 行为 |
|---|---|---|
| 舞台 / 人物震动 Shake | Stage 或 Character；人物实例 ID；强度 0–5；非零方向向量；频率 0.1–60 Hz；衰减开关 | 强度 1 的最大偏移为父舞台宽/高的 2%；方向自动归一化，`(1,0)` 横向、`(0,1)` 纵向。正弦波叠加在 Move/Gesture 之上，结束、取消、快进归零 |
| 遮罩淡入淡出 Cover | RGBA 颜色各 0–1、目标透明度 0–1、时长、保持时间、覆盖整个阅读页 | 最终 Alpha = 颜色 Alpha × 目标透明度；从当前遮罩颜色渐变，保持后动作完成，**遮罩仍保留**。撤幕再写一条透明度 0 的 Cover |
| 短暂闪光 Flash | 与 Cover 相同；编辑器新选此类型默认白色、透明度 0.35 | 时长的一半淡入、一半淡出，中间插入保持时间；结束恢复闪光前遮罩。时长 0 且保持 0 时不绘制闪光 |
| 图片交叉淡化 CrossFade | Background 或 Character；人物实例 ID；新图片键；时长；缓动 | 目标必须已显示。新图准备好后，旧/新两层分别淡出/淡入；保留位置、镜像、层级、亮度和局部透明度。空槽请先 Show |

Shake 不移动对白和菜单。默认 Cover/Flash 在背景和人物之上、阅读文字之下；“覆盖整个阅读页”勾选后包含对白和阅读按钮，但不覆盖独立设置/存档/Loading 页面。遮罩不拦截点击。

**接管规则：**同目标 Shake 相互接管，与 Move 相互独立。Cover 与 Flash 共用唯一 `Mask/cover` 通道；新指令取消旧指令，包括其延迟/保持阶段。取消 Flash 会恢复此前稳定遮罩，再启动新指令。接管 CrossFade 时先收束旧淡化到其新图，再从该图向下一张淡化，不保留无限多图层。普通 Replace/Hide 也会清掉旧淡化层；旧资源在不再可见且无其他实例使用时释放。

新图加载期间保持原画面，并允许其他已启动动作继续；**Parallel 不跳过资源准备**，新图就绪、句柄建立后才进入后续对白。缺图会给出指令/资源错误，不显示白框、不无限等待。不能以更换资源键指向同一张图片来验收换表情。

系统设置提供“震动强度 / 闪光强度”，从左到右为正常、减弱（25%）、关闭。偏好持久化到账号，立即作用于当前会话；只改变 Shake/Flash 可见幅度，不缩短等待、不改变最终遮罩。普通 Cover 不受闪光偏好影响，否则黑幕后换景会暴露。新增设置由 EUI 开发中心 API 的一次性导入迁移维护，后续绑定调整仍通过中心生成。

**保存恢复：**Schema 4 增加遮罩颜色和覆盖范围，接受 Schema 1–3 并补无遮罩默认值。稳定点保存时 Cover 投影到最终颜色、CrossFade 保存新图、Shake 偏移丢弃、Flash 保存闪光前遮罩；恢复不重播这些过渡。仍不支持过渡帧存档，已有对白/配音/已读规则不变。

### 3.6 粒子效果与声音编排（E3）

本批 E3 已获用户“全部成功”反馈，按用户验收通过收束；没有提供新的 XML 或复跑计数。效果 ID 与人物 ID、动作 ID 相互独立。

| 指令 | 配置与行为 |
|---|---|
| EffectPlay / 播放粒子效果 | ResourceKey、InstanceId、Persistent、KeepOnSceneChange、BindingId、Position、Scale、Layer；相同 ID 原实例被替换 |
| EffectStop / 停止粒子效果 | InstanceId；立即停止并释放粒子实例与资源租约；不存在时安全忽略 |
| BGM / 背景音乐 | 原音频表 BGM 键；Volume 0–1、Duration、Delay、Ease、Parallel、ActionId；有旧轨时交叉渐变，无旧轨时淡入 |
| BGMStop / 停止背景音乐 | Duration、Delay、Ease、Parallel、ActionId；完成后释放音轨与租约 |
| AmbientPlay / 播放环境循环音 | 使用 SFX 表项；独立 InstanceId、Volume 与渐变参数、KeepOnSceneChange；同 ID 接管，不无限叠轨 |
| AmbientStop / 停止环境循环音 | InstanceId 与渐变参数；不存在时安全忽略，仍消费设定的有限动作时间 |
| AmbientVolume / 环境音量 | 已启动 InstanceId、Volume 与渐变参数；不存在则定位报错 |

**粒子位置**：舞台绑定以左下 `(0,0)`、右上 `(1,1)`；人物绑定以人物中心为 `(0,0)` 的局部偏移，随人物移动/缩放/旋转/镜像和震动。坐标 -2～3，缩放各轴 0.05～5，层级 -100～100；层级只排序同绑定的粒子实例，不把效果提到阅读按钮上方。舞台粒子处于人物之上、Cover 和阅读 UI 之下。绑定人物退场立即清理；恢复时人物必须存在。

**资源范围**：`rain`、`lastlight_motes`、`lastlight_spark` 对应 `Effects/Narrative` 下的 Prefab。根节点单个 ParticleSystem、Local 空间、最多 1024 粒子，周期/常量或双常量寿命不超过 60 秒。首批将位置、二维尺寸、颜色和旋转映射为 UI 矩形，不消费原生 Renderer 材质。复杂系统会拒绝或不呈现，勿把任意项目特效当作兼容素材。每会话最多 64 个视觉实例、64 个当前循环音；交叉渐变期间每个音轨可临时保留一个退出实例。

**时序**：视觉创建/停止是即时步骤，不设置时长/延迟；自然结束才回收的一次性粒子与持续粒子均不阻塞对白。声音 Duration 仅表示渐变时长；Parallel 不勾时等渐变，勾选后可与对白并行。ActionId 留空使用 CommandId。新渐变从当前增益继续，原句柄变 Cancelled，等待旧句柄随即解除；交叉渐变再次接管时丢弃更老的退出轨，保留当前轨的实际音量继续淡出。AmbientVolume/BGMStop 的延迟阶段维持已有声音；新播放的入轨在延迟阶段暂停，旧出轨保持当前音量。

| 行为 | E3 约定 |
|---|---|
| 一次性粒子 | 不勾 Persistent；非循环模拟，粒子全部消失后释放；已读快进跳过或移除，不保存 |
| 持续粒子 | 循环模拟；通过 EffectStop、换场规则、绑定目标退出或会话退出释放 |
| 换场 | Background Show/Replace/Hide、章节变化为边界；仅勾保留的持续粒子与环境音留下；BGM 保留。CrossFade 为同场图片过渡，不清理 |
| 暂停 | 粒子模拟、渐变时间、音频输出一起暂停；恢复不新增实例，不使用全局 timeScale |
| 1X/2X/3X | 仅加速有限渐变与剧情等待；粒子和循环音按正常速度，音高不变 |
| 快进 | 渐变收敛到目标音量；持续实例按 ID 接管，不堆积；不播放新的短促装饰 |
| 稳定点存档 | Schema 5 记录持续粒子配置/存在性与循环音的最终音量；正在停止的轨不记录，交叉渐变只记录新目标轨 |
| 恢复 | Loading 阶段先校验并加载；提交时重建持续状态，不续播粒子相位/采样位置，不重播一次性粒子、SFX 或 Voice |
| 旧档 | Schema 1–4 补空实例列表，保留旧 BgmKey 并迁移成音量 1 的循环轨；剧情语义指纹仍须兼容 |
| 试播末尾 | 只等待有限音量渐变，持续实例继续显示；停止、重播、关窗、重编译释放全部 |

配置例：EffectPlay `lastlight_motes`，实例 `roof-motes`，位置 `(0.5,0.5)`、缩放 `(1,1)`、Persistent；AmbientPlay `lastlight_rooftop_wind`，实例 `roof-wind`、Volume `0.3`、Duration `1.5`、Parallel；中间插入对白；离开时 EffectStop `roof-motes`，AmbientStop `roof-wind`、Duration `2`。雨资源可用 `rain`、位置 `(0.5,1.05)`，用于合适的下雨场景；当前黄昏天台正文使用光点，不为展示雨效改写天气。

实际听音、粒子形态、暂停后继续、两个画面比例和真机性能仍需人工确认。每个粒子由 UI 顶点表达；本实现不承诺完整 ParticleSystem Renderer 或其他特效系统兼容性。

### 3.7 剧情对白显隐（E4）

选择独立步骤“剧情对白显隐”，设置“显示剧情对白层”。隐藏时仍执行后续背景、人物、声音、动作及 Wait；没有额外时长或资源。需要一段无对白演出时，将隐藏指令放到演出之前，并使用现有有限 Wait / WaitActions 控制时长。

可显式显示，也会在下一句 Say（含标题和旁白）、选择或结局/故障/取消处自动恢复。不能用它把后续需要输入的文本/选择藏住。它不改变玩家的“隐藏”状态、不移除菜单和阅读控制；玩家手动隐藏仍会暂停，首次推进仅恢复玩家 UI。

## 4. 动作公共参数与范围

以下公共参数适用于 Opacity、Move、Scale、Rotate、Mirror、Layer、Gesture；不适用于 Say、背景音乐或基础 Show/Hide。

| 字段 | 如何配置 |
|---|---|
| 实例 ID | 人物动作填写已显示实例，例如 `wan`；Stage / Background 透明度不用填 |
| 动作 ID | 可留空。留空时该动作的句柄就是本步骤 ID；只有需要被等待组按名字引用时才填，建议「前缀-用途」，例如 `wan_walk_left`；同一章节内句柄不重复 |
| 动作秒数 Duration | 有限且不小于 0；0 即时完成。Mirror / Layer 必须为 0 |
| 开始延迟 Delay | 有限且不小于 0；先等这段时间，再执行动作 |
| 并行启动 Parallel | 不勾：执行完本动作才到下一步；勾选：立即进入下一步，动作继续执行 |
| 缓动 Ease | 人物动作提供 Linear、SmoothStep、EaseIn、EaseOut。Opacity 没有此编辑字段，保持线性 |

缓动：Linear 匀速；SmoothStep 起止平缓；EaseIn 由慢到快；EaseOut 由快到慢。Mirror/Layer 是离散切换，缓动不会使其产生连续动画。

| 效果参数 | 当前允许范围 |
|---|---|
| Normalized 坐标 | X/Y 各为 -2～3；0～1 是父舞台范围，超出可用于进出场 |
| Scale | X/Y 各为 0.05～5；不能用负缩放代替镜像开关 |
| Rotate | -3600°～3600° |
| Layer | 整数 -100～100 |
| Gesture 强度 | 0～5；0 无位移，建议从 0.2～0.5 的克制幅度开始调 |
| Opacity / DimFactor | 0～1 |

归一化位置使用**立绘根节点锚点区域的中心**，不是脚底，也不是可见人物轮廓中心。X 向右、Y 向上；当前正式布局的命名中心约为左 `(0.26,0.335)`、中 `(0.50,0.395)`、右 `(0.74,0.335)`。这是当前布局值，布局调整后会改变；一般站位优先用 Named，画面外或精细编排用 Normalized。坐标略超过边界不保证整张宽立绘已经出画，仍需实际看画面。

勾选“移动完成后退场”时，必须使用画面外 Normalized 目标（X 或 Y 超出 0～1）。完成后移除实例、取消该人物其他动作，释放位置。

### 并行、等待和接管

1. 同一实例、不同属性可并行，例如同时移动和缩放。
2. 同一实例、同一属性由后来的动作接管；旧动作取消，新动作从当前值继续。新动作即使带延迟，也在启动时立即取消旧动作，延迟期间保持接管值。
3. 等待组把 Cancelled 也视为结束，因此等待被接管的旧动作不会挂住。要等到最终效果，必须把新动作 ID 也列入等待。
4. Move 在启动时立即预占命名目的地，包括延迟阶段；直接向别人占用的位置移动会报错。双人交换先让出位置。
5. 只能等待已经启动过的动作；不能填后续步骤或未走分支的动作 ID。

## 5. 直接照着配置的例子

表里的每一行对应编辑器的一条段内步骤。未写的字段保留默认值；动作 ID 在你的章节中保持唯一。

### A. 林晚在左边说话

| 顺序 | 步骤 | 填写 |
|---|---|---|
| 1 | 立绘 → 显示 | 图片 `lastlight_alice`；实例 `wan`；Named 左侧；过渡 0.3 秒 |
| 2 | 角色强调 | Auto；其他人物亮度 0.72 |
| 3 | 对白 / 旁白 | 角色 `lastlight_wan`；台词“等这盏灯亮起来，我们就一起下去。”；配音可留空 |

已经有 `wan` 时不要重复创建，改用 Move 设置站位。说话人的姓名框位置仍使用正式 UI 布局。

### B. 一边走向右侧，一边说话

前提：`wan` 已在场，右侧空闲。

| 顺序 | 步骤 | 填写 |
|---|---|---|
| 1 | 人物移动 | 实例 `wan`；动作 `wan_walk_right`；Named 右侧；1.2 秒；SmoothStep；勾并行 |
| 2 | 对白 / 旁白 | 角色 `lastlight_wan`；填写行走时说的话 |
| 3 | 等待动作组 | `wan_walk_right` |
| 4 | 对白 / 旁白 | 写到位后的台词 |

如果希望走完才说话，步骤 1 不勾并行，就不必另写等待组。

### C. 两人一起淡出，接空镜旁白

前提：`wan`、`zhou` 已在场。

| 顺序 | 步骤 | 填写 |
|---|---|---|
| 1 | 透明度动作 | Character；`wan`；动作 `wan_fade_out`；透明度 0；1 秒；并行 |
| 2 | 透明度动作 | Character；`zhou`；动作 `zhou_fade_out`；透明度 0；1.2 秒；延迟 0.15 秒；并行 |
| 3 | 等待动作组 | `wan_fade_out`、`zhou_fade_out` |
| 4 | 立绘 → 隐藏 | 实例 `wan`；过渡 0；资源键留空 |
| 5 | 立绘 → 隐藏 | 实例 `zhou`；过渡 0；资源键留空 |
| 6 | 对白 / 旁白 | 角色留空，写空镜旁白 |

需要淡出期间就出现旁白时，把一句旁白放在步骤 2 与步骤 3 之间。

### D. 双人换位

前提：`wan` 在左，`zhou` 在右。

| 顺序 | 步骤 | 填写 |
|---|---|---|
| 1 | 人物移动 | `wan`；动作 `wan_make_room`；Normalized `(0.32,0.335)`；0.8 秒；不勾并行 |
| 2 | 人物移动 | `zhou`；动作 `zhou_go_left`；Named 左侧；1.2 秒；并行 |
| 3 | 人物移动 | `wan`；动作 `wan_go_right`；Named 右侧；1.2 秒；并行 |
| 4 | 等待动作组 | `zhou_go_left`、`wan_go_right` |

人物仍分别叫 `wan` 和 `zhou`，不需要交换 ID。临时坐标不占左中右命名位置。

### E. 点头，或者持续倾身

- 点头：Gesture = Nod，实例 `wan`，动作 `wan_nod`，时长 0.6 秒，强度 0.4。完成后自动回到原姿态。
- 持续倾身：Scale 到 `(1.025,1.025)` 与 Rotate 到 `-2°`，分别起动作 ID，勾并行。需要坐直时，再分别配置 Scale `(1,1)` 与 Rotate `0°`。这两种持续变换不会自行复位。

### F. 从画面外入场，再离开

1. 立绘 Show：实例 `zhou`，图片 `lastlight_zhou`，Normalized `(1.25,0.335)`，过渡 0。
2. Move：实例 `zhou`，动作 `zhou_enter`，Named 右侧，1.6 秒，SmoothStep。
3. 中间配置对白。
4. Move：实例 `zhou`，动作 `zhou_exit`，Normalized `(1.4,0.335)`，1.6 秒，勾“移动完成后退场”。

实际是否完全出画取决于图片与根节点宽度，可调远一些。下次再 Show 同 ID 会重新建立基准姿态。

上述效果在正式小说中的具体位置与动作后缀见 [SampleWalkthrough](SampleWalkthrough.md)。

## 6. 阅读、存档与预览对效果的影响

| 行为 | 当前约定 |
|---|---|
| 打开菜单、历史、设置 | 暂停演出；嵌套页面全部解除相应暂停后继续 |
| 1X / 2X / 3X | 加速演出动作和阅读节奏，不改变 Voice/BGM/SFX 音高 |
| 仅已读快进 | 演出收敛到最终值，未读对白和选项停止 |
| 保存 | 完整对白或选项就绪后保存；活动动作的最终值写进副本，当前屏幕不被强制推进 |
| 恢复 | 恢复最终位置、变换、透明度、层级与强调状态；临时手势不保存，不恢复过渡中间帧 |
| 返回菜单 / 换会话 | 清理旧动作与资源，迟到操作不应影响新会话 |
| 编辑器节点静态预览 | 不能代表动作中间帧；它不执行完整动作管线，实际时序请从 Play 主菜单试播 |

新版剧情改动可能使旧档因内容指纹不匹配被拒绝，首次验收从新游戏开始。

## 8. 常见配置问题

| 现象 | 先检查 |
|---|---|
| 选了说话人，但画面没有人物 | Say 不会自动 Show；先配置立绘显示 |
| 改了 Say 的角色，人物没有移动 | 用 Move 改站位；角色键不控制位置 |
| 刚才变暗的人没有恢复 | Manual 持续生效，改回 Auto / Off；若改的是 Opacity，应另设透明度 1 |
| 人物透明后无法在该位置 Show 新人 | 透明度 0 不释放实例，先 Hide |
| 动作不执行 | 检查实例是否已 Show、动作 ID 是否唯一、时长是否合法、会话是否暂停 |
| 换位报“位置已占用” | 先移到 Normalized 临时位置；不要同时占用对方的 Named 位置 |
| 第二个旋转覆盖第一个 | 同属性接管是既定规则；想依次完成就取消并行或加等待 |
| 图像替换没有看到表情变化 | 使用 `lastlight_wan_smile`；`alice_smile` 仍是兼容旧键，指向原图。周砚仍只有一张正式立绘 |
| 写了闪白但没有效果 | 使用 Flash，检查颜色是否为白、Alpha/透明度是否大于 0、时长/保持是否均为 0，以及系统设置是否关闭闪光 |

## 9. E5：镜头、擦除与演出预设

本节实现已获用户独立反馈“全部通过”，E5 文档据此收束；未提供 XML 或复跑总数，不将用例定义数量写成测试结果。滤镜暂缓与平台待办仍保留。

### 舞台镜头

“这一步做什么”选择 **舞台镜头**。缩放为绝对目标值 **1–3**，1 为原构图；平移为屏幕宽高的归一化位移，正 X 向右、正 Y 向上，表示移动舞台内容。每轴绝对值不得超过 `(缩放−1)/2`。例如缩放 `1.2`、平移 `(0.05,0)`、时长 `1`、SmoothStep、并行，可在下一句对白期间缓慢推近右移。复位填缩放 `1`、平移 `(0,0)`；不允许缩小到原构图以下。

镜头同时变换背景、人物和舞台粒子；人物绑定粒子继承人物变换。对白、姓名、选项、菜单、标题/全屏旁白和遮罩保持原位置。人物 Move、Scale、Gesture、角色 Shake 与镜头叠加，Stage Shake 在镜头之后叠加。镜头采用独立 Camera 属性通道，不接管人物动作或舞台透明度。同通道新动作从当前值继续，旧动作标记取消；动作 ID、延迟、缓动、并行与等待组沿用现有规则。

平移范围保证**原来铺满视口的矩形背景**在镜头动画中继续覆盖视口；默认背景 Image 不保留宽高比，继续沿用原素材铺设方式。自定义留白、非中心布局、透明边、旋转或 Preserve Aspect 素材需要另做构图检查。瞬时舞台震动仍会移动画面，需为震动预留额外裁切余量，避免将平移推到边界后再震动。

镜头保持到下一条镜头指令，普通 Background 换场不会自动归零；需要原构图时显式复位。LastLight 每个对话节点开头都设置中性镜头，便于独立试播。

### 背景擦除转场

选择 **背景擦除转场**，填写已配表的新背景键、方向（左→右、右→左、下→上、上→下）、时长、延迟、缓动、并行与动作 ID。须先显示背景。新图加载完成后开始计时；延迟期间只显示旧图，随后按方向揭示新图。

擦除复用正式双图 Item 与资源租约，用 Image Filled 裁切新图；没有新 Shader 或全局管理器。两张图保持整体透明度，由形状推进转场。完成/接管时恢复克隆 Image 原类型与填充配置，释放不再使用的旧图。擦除与背景交叉淡化共用图片通道，接管先收束到旧动作的目标图，再开始下一次过渡；正常 Replace/Hide 也会取消它。资源缺失时定位到当前指令并保留原画面，退出时释放已取得的租约。它是同场图片过渡，不触发 Background 场景切换的媒体清理规则。

### 参数化演出预设

对话内容的段内步骤旁点 **插入演出预设…**。选择预设，设置时长 `(0,30]` 秒与强度 `0.1–3`，在节点末尾插入普通指令；使用现有列表调整顺序。每次插入生成唯一指令/动作 ID 与 WaitActions，支持 Undo；不修改共用运行状态，也不建立运行时宏解释器。

| 预设 | 参数与使用前提 | 展开后的效果 |
|---|---|---|
| 进场 | 新人物实例 ID、立绘键、左/中/右位置；强度不参与此预设 | 从画面外 Show，Move 到命名位置，等待移动完成 |
| 受击 | 已在场人物实例 ID；可选 SFX 键 | 人物震动与短闪并行，可配短音效，等待有限动作 |
| 回忆氛围 | 时长、强度 | 居中推近与低透明度暖色遮罩并行，等待后保持 |
| 镜头/遮罩复位 | 时长；强度不参与此预设 | 镜头回到 1 倍/零位移、遮罩归零，等待完成 |

回忆预设是暖色覆盖，不是真正的泛黄、模糊或灰阶滤镜；会接管当前镜头和 Cover 通道。复位清空当前遮罩，不恢复任意更早的遮罩历史。插入后可以逐项修改/删除，包括调整等待位置；不自动创建人物、音效资源或配表项。修改配表仍通过配表中心。

### 暂停、恢复与编辑态试播

Camera / Wipe 复用会话时钟，响应暂停、阅读倍率、快进和同属性接管；停止、退出和重开清理正式视图，镜头回到原始变换。Schema **6** 记录镜头最终缩放/位移；稳定点捕获将未完成镜头投影到目标值但不推进现场。擦除保存目标背景，不保存中间裁切或重播转场。Schema 1–5 镜头缺省为中性，仍需满足故事指纹检查；LastLight 本次新增指令改变指纹，应从新游戏验收。

“播放节点”复用同一 NovelSession 和正式阅读页适配，镜头和擦除进入节点末尾有限动作等待；持续粒子/循环音不进入无限等待。沿用停止、复位、关窗、重编译的释放路径。预设展开后直接在当前节点试播；没有另建预设时间轴、多节点编辑态串播或共享预设资源库。

### 滤镜评估结论

现有正式舞台是 Overlay uGUI，框架 Camera API 面向场景 Cinemachine 镜头；直接套用场景后处理不能保证影响 UI 且保持文字清晰。本轮选择 RectTransform 镜头与已有 Image 裁切，不新增渲染依赖。模糊、灰阶、真正的色调滤镜暂缓，后续需在 Unity 验证 UI 材质、遮罩、粒子混合和目标设备开销，再决定实现；本轮没有性能实测结论。


## 10. 多语言（配表）

同一份剧情可以按语言显示不同的正文、选项、提示、章节名与界面文案。语言清单暂定简体（源语言）、
繁体、日语、英语，可以继续加。唯一固定的约定是**源语言列固定叫 `zh_Hans`**。

| 表 | 用途 | 什么时候改 |
|---|---|---|
| `novel_languages` | 语言清单（`id / displayName / order / isSource`） | 新增语言 |
| `novel_content_text` | 剧情内容文案（`key, zh_Hans, zh_Hant, ja, en`） | 随内容增长 |
| `novel_ui_text` | 界面文案（同列） | 只有增删改 UI 时才动 |

在流程里填 Key：

| 编辑器字段 | 填什么 |
|---|---|
| 对白 → 多语言 Key | `text.〈剧情 ID〉.〈台词 ID〉`，留空即用上面的原文 |
| 选项 / 分流 → 多语言 Key | `option.〈剧情 ID〉.〈选项 ID〉` |
| 选择提示 → 提示多语言 Key | `prompt.〈剧情 ID〉.〈节点 ID〉` |
| 章节名称 → 章节名多语言 Key | `chapter.〈剧情 ID〉.〈章节 ID〉`（剧情显示名用 `story.〈剧情 ID〉`） |
| 角色名 | 内容表里的 `character.〈角色键〉`；未填时用角色表的 displayName |
| 说话人称呼 → 说话人称呼 Key | `speaker.〈语义〉`，例如 `speaker.unknown`；**只用于揭晓前的临时称呼**，留空即用角色名 |

Key 是**稳定标识**：它由已有的稳定 ID 拼出，重新导入换个顺序、改个错字都不会变，译文不会跟错行。
填完 Key 的下一行就逐语言预览——命中的显示译文，没命中的显示「缺条目 → 回退：〈原文〉」，
当前语言前面有 ● 标记。**留空就是原文，不会被强制填写。**

回退链固定为：目标语言列 → 源语言列（`zh_Hans`）→ 资产里的原文。某一语言没翻译时显示的是源语言，不会出现空白；
Key 查不到也不报错，直接回退原文。说话人显示名再往前多一步：**称呼 Key → `character.〈角色键〉` → `novel_characters.displayName`**。

**揭晓前显示 ？？？**：给那几句填真实角色键（不要为了显示占位名而留空角色键），再加
`说话人称呼 Key` = `speaker.unknown`（模板已在内容表里备好 `？？？`）；揭晓真名之后的句子把称呼 Key 留空即可。
称呼 Key 只覆盖显示名：**它不进存档语义指纹**，所以给既有剧情补上它不会作废玩家存档；
它也不参与「角色强调 → Auto」的角色键匹配；历史回看按当时的称呼 Key 重新解析，
所以旧句不会因为后面揭晓了真名而变成真名。想换一种临时称呼（例如`神秘的声音`）时，
在内容表新开一个 `speaker.〈语义〉` Key，不要复用带角色键的写法。

**切换语言**：节点 / 章节 Inspector 顶部的「全局语言」下拉，或流程窗口工具栏的语言菜单。
它写入的是全局偏好，**不进存档、不影响剧情指纹**，所以改语言、加译文都不会让既有存档失效；
界面立刻跟随，已经开始的会话里正文也按新语言重建。

**加一种语言**：`novel_languages` 加一行，两张文案表与对应 Row 各加一列，
`NovelLocalizer.Pick` 加一个分支，然后烘焙。

两条已知边界：

- **文字节奏按原文编排**：结构化文字节奏的 `At` 是原文的 Unicode 标量位置，并且按原文长度校验。
  译文长短不同不会报错也不会崩，但越界的节奏点在该语言下不会触发。译文需要不同的停顿/变速位置时，
  按译文重新编排这一句的节奏值即可，不要把译文硬凑成原文长度。
- 改完配表**必须烘焙**；Windows 上若报「无法删除要被替换的文件」，先卸载已加载资源再烘焙，
  烘焙后还要让资源库刷新一次，否则读到的仍是旧表。

## 11. UI 皮肤（按小说换图）

一套皮肤 = 若干「某个页面上的某个图片节点 → 另一张图」的覆盖记录，按小说赋值。
本期**只换图片，不动位置与大小**；各小说自己的布局调整仍走布局窗口。

| 表 | 用途 |
|---|---|
| `novel_skins` | 皮肤清单（`skinId, displayName`）。没有任何覆盖行的皮肤等于沿用 Prefab 外观 |
| `novel_skin_sprites` | 覆盖行：`id, skinId, page, control, node, spritePath` |
| `novel_story_skin` | 把皮肤赋给某部剧情：`storyId, skinId`。没有记录的剧情不套皮肤 |

覆盖行的写法：

| 列 | 填什么 |
|---|---|
| `id` | 约定 `skinId.page.control.node`，只要求唯一 |
| `page` | 页面 Prefab 名，例如 `EUINovelReaderPage`、`EUINovelReadingMenuPage`、`EUIMainPanel` |
| `control` | EUI 绑定控件名，例如 `Menu`、`History`；**留空表示页面根** |
| `node` | 锚点下的相对节点路径，例如 `SkinBorder`、`Border/Fill`；**留空表示锚点自身** |
| `spritePath` | Resources 下不含扩展名的图片路径，例如 `UI/Common/Atlas/Novel/return` |

`control` 与 `node` 组合起来，同名节点就能分别覆盖：阅读页上很多按钮下都有叫 `SkinIcon` 的图，
写 `History` / `SkinIcon` 只会换历史按钮那一个。

**不知道能覆盖哪些图时**，运行菜单 `Ember/视觉小说/导出皮肤可覆盖图片清单`：
也可以直接在布局窗口选中元素后用「把此元素加入皮肤清单（复制 CSV 行）」单个取行。

它扫描全部页面 Prefab（含主界面），列出每张图片的「页面 / 控件 / 节点 / 当前图片」，
并把待填的 CSV 行直接放进剪贴板——把 `SKINID` 换成皮肤标识即可用。

**一条硬约束**：`spritePath` 必须是项目 `Resources` 下的图片。Unity 内置的 `UISprite`
（`Resources/unity_builtin_extra`，不少按钮底框用的就是它）**无法用路径表示**，只能当被替换方；
清单里这类会标成「内置，不可寻址」，要换它就必须指向一张项目里的图。

**运行期怎么生效**：页面绑定完成后按名换图，不修改任何 Prefab、Binding 或布局；
主界面与阅读页读的是同一部小说的皮肤（当前小说取自小说库），所以换小说就换整套外观。
