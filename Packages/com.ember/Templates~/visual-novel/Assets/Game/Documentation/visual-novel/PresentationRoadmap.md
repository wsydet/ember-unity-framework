### 0.10.1 表现与交互修复批（未新增演出能力）

这一批不是新演出能力，而是把消费项目在制作中被迫绕开的缺陷修回模板本身：
阅读页不透明底板、背景同键重设幂等、空实例 ID 立绘隐藏的退化语义与诊断、章节卡与背景顺序、
循环音 Mixer 分组。主菜单存档入口**保持原设计**（继续游戏续读最新进度、读取存档打开槽位页），
不属于本批改动。逐项范围见
[配置手册第 12 节](EffectConfiguration.md#12-0101-表现与交互修复批) 与 [实现说明](Implementation.md)。

它不改变「未支持效果」清单，也不把任何未来拓展项提前实施；仍待人工验收的项为：

| 待验收 | 为什么不能由本批自动用例替代 |
|---|---|
| 循环 BGM 的实际听音（含接入 Mixer 后的音量、分组静音、暂停恢复） | 本仓库没有配制 Mixer，模板也不带；会话层只能验证「角色声明与音量不叠乘」，出声必须人工听 |
| 消费项目升级后的画面观感 | 底板、背景重设与隐藏语义都直接改变观感，必须由消费项目在实际剧情上确认 |
| 章节卡开场（背景排在卡片之后）的实际画面 | 底板兜底由结构用例守住，观感仍需人工看 |
| 主菜单存档入口 | **未改动**，无需验收；「继续游戏」续读最新进度、「读取存档」打开槽位页 |

| 未来拓展 | 当前边界 | 重新启动条件与最小验收 |
|---|---|---|
| E5 模糊、灰阶、真正的色调滤镜 | 暖色遮罩已经交付，但不等同于后处理；不新增默认渲染依赖 | 有具体镜头素材需求后，先验证 Overlay UI/粒子/遮罩适配与目标设备性能，再补配置、恢复、资源释放和试播 |
| E5 更多复杂转场 | 已有交叉淡化、四向背景擦除继续可用 | 确定具体转场样式和素材后，复用双图/动作管线，验证接管、快进、存读档和清理 |
| E6 Live2D / Spine 动态立绘 | 未实现，不强制基础模板依赖插件 | 确定模型、插件版本、授权与目标平台，适配现有人物实例、动作和生命周期接口 |
| E6 眨眼与配音口型 | 未实现，现有配音等待规则保留 | 确定模型参数与音频驱动方式，补暂停/倍率/快进、无配音回退、读档和退出验证 |
| E6 视频播放 | 未实现 | 确定编码、平台、跳过与等待规则，补加载失败、暂停、存读档策略及解码资源释放 |
| 制作工具增强 | 已有可编辑预设展开与单节点试播；未实现共享预设资产库、多节点时间轴、拖动与倒放 | 当实际内容制作需要复用或跨节点编排时再设计，保持预览隔离，不污染正式资产与存档 |

未来启动其中任何一项时，从当前封存版本加载模板，在 Assets 实施数据、运行、编辑、示例、测试与文档闭环，再经项目中心保存和显式 Bump。不要将这里的规划当作已实现 API。

移动端/异形屏、极长文本与大存档性能、Player 构建、完整回归 XML 归档及消费项目部署验证属于**交付与目标平台验收**，不是可宣称完成的功能拓展；在实际面向相应平台交付时补验。本次基础框架收尾不代表这些验证已通过。

## 目标与现状

让剧情作者在现有剧情编辑器中组合人物、画面、声音和文字演出，无需为每段剧情单独编写脚本。按本文顺序逐批实施，每批包含数据、运行、编辑、示例和验证闭环。

当前支持背景/立绘显示、替换、隐藏与透明度过渡，左/中/右固定立绘槽位，BGM/SFX/Voice 播放、逐字显示、独立 Wait，以及阅读辅助和稳定点存读档。

E0 新增透明度并行动作、等待组与稳定点最终透明度恢复。当前 Assets 已加入 E1 位移和 E2 震动、遮罩及双图过渡，本轮测试已获用户确认全部通过；E3 已加入受控 ParticleSystem 实例（用户验收通过）；完整过渡帧恢复仍未支持。静态布局编辑不等于剧情移动；替换 Sprite 不等于新旧图片交叉淡化；SFX 是音效，不是视觉特效。本文“未支持”指模板尚无可直接编排的完整能力，不代表底层框架没有可复用 API。

## E0：先建立演出执行闭环

范围：

- 定义可寻址的舞台、背景、人物实例、遮罩与效果实例；人物身份独立于左中右位置，移动后仍能正确换表情、隐藏和存档。同一人物出现多个实例时使用不同实例 ID。
- 建立动作句柄、完成/取消状态；支持顺序执行、并行启动、等待指定动作或一组动作，以及开始延迟。已有 Wait 保留为纯计时等待。
- 同一目标同一属性的动作默认由新动作接管，从当前值继续；不同属性可并行。编辑器提示明显冲突；后续取消的旧动作不得覆盖新动作结果。
- 接入会话暂停、阅读倍率、快进、跳场、读档和退出清理。运行观察展示正在执行的动作、目标和等待原因。
- 保持旧剧情语义；序列化枚举不重排，新参数提供兼容默认值。先核对框架 API 速查手册，复用已有资源、音频和调度能力，不建立第二套全局 Manager。
- 确定存档版本迁移：旧档提供默认变换和空效果列表；无法兼容时明确提示，不能错误恢复。沿用对白/选项稳定点存档，不在任意过渡帧保存。

验收：两个动作能同时运行并正确等待；并行动作期间可显示对白；暂停后进度不变；恢复继续；快进收敛到最终状态；同属性接管无回弹；退出后无回调再访问已销毁页面。使用最小实际透明度动作贯通管线，避免只验证空壳调度器。

E0 交付说明：实际可用目标为舞台、背景和最多三个独立身份的人物实例。E0 时 Mask/Effect 为身份契约预留；E2 新增单一 Cover/Flash 遮罩，Effect 由 E3 的独立播放/停止指令管理。E0 Opacity 的参数校验会明确拒绝。旧档补默认变换与空效果，E0 仅执行 Opacity。独立示例、编辑和保存说明见 [Authoring](Authoring.md#e0透明度动作与等待)，失败与复验记录见 [Implementation](Implementation.md)。

## E1：立绘移动与角色强调

范围：

- 支持左/中/右命名位置与归一化舞台坐标；配置时长和有限缓动预设，避免把屏幕像素作为剧情数据。
- 支持中间移到两侧并返回、从画面外进入和退出；移动到已占用命名位置必须明确报冲突或显式替换，不静默丢失角色。
- 支持缩放、旋转、镜像和层级调整；提供跳动/点头等可复用动作组合，动作结束可恢复基准姿态。
- 支持说话者高亮、非说话者变暗；可关闭自动强调或手动指定，旁白不错误选中角色。
- 保存人物最终位置、变换、层级与强调状态；人物实例身份不随槽位改变。

验收：同一人物完成“中 → 左 → 右 → 中”，途中更换表情仍作用于正确实例；双人交换位置可编排；退出后再次入场无残留变换；16:9、4:3 的目标位置一致；读档还原位置和层级。

## E2：震动与基础画面过渡

范围：

- 震动目标可选舞台或单个人物，提供强度、方向、频率、时长及衰减；舞台震动默认不带动对白和菜单。
- 震动作为基准位置上的临时偏移，与人物移动叠加；完成、取消和快进都清除偏移，不能累积位置漂移。
- 黑幕/白幕淡入淡出、短暂闪白；提供颜色、透明度、时长和保持时间。遮罩默认位于舞台之上、对白之下，可显式选择全画面覆盖。
- 背景和人物表情支持真正的双图交叉淡化；旧资源保留到不可见后再释放，处理空槽、缺图和中途替换。

验收：人物一边移动一边抖动，结束位置正确；并行震屏和音效时序一致；反复震动不漂移；交叉淡化中间帧同时保留新旧图；空槽隐藏无白框；黑幕下换景后揭幕无旧图闪现。为震动/闪烁提供减弱或关闭设置，设置不改变剧情等待与最终状态。

## E3：视觉特效与声音编排

范围：

- 通过资源键播放/停止效果 Prefab，支持一次性与持续效果；配置实例 ID、位置、层级、缩放，以及绑定人物或舞台。首批限定一种可控实现（优先评估 ParticleSystem），不一次承诺所有特效系统。
- 一次性效果结束自动回收；持续效果显式停止，并明确换场时保留或清理。首批提供雨/光点等持续效果和一个短促受击效果示例。
- BGM 支持剧情控制播放、停止、淡入淡出及交叉渐变；环境循环音有独立实例 ID、停止和音量控制；短促 SFX 保留现有播放方式。
- 剧情音量与玩家设置音量叠乘，不能覆盖玩家偏好；按句自动等待配音的现有规则保留。
- 持续音效与视觉效果使用资源句柄统一清理，读档恢复持续状态，不重播一次性爆炸、受击音效或配音。

验收：雨与循环雨声可跨对白持续、暂停和停止；菜单暂停后恢复无重叠实例；快读/重开多次不重复生成；缺失资源显示可定位错误；切场和退出全部释放。读档仅恢复声明为持续的效果，粒子相位和音频采样位置不要求逐帧一致。

## E4：文字与对白表现

范围：

- 句中停顿、片段速度和即时显示片段；结构化节奏数据与正文分离，不向历史显示控制标记。
- 保持“第一次推进补全文字、第二次推进下一句”；补全会跳过句内停顿，自动模式仍正确等待配音。
- 剧情控制对话框显隐，与玩家手动隐藏区分；定义无对白演出结束后的恢复点，不能使玩家无法继续。
- 居中标题/章节卡、全屏旁白模式与普通对白恢复；长文分页需明确页内/句间推进、自动播放和历史记录规则。

验收：停顿、手动补全、自动与已读快进组合无卡死；历史正文完整且无控制标记；字号变化和长文本不会遮住推进入口；切模式及读档恢复正确。

## E5：镜头、复杂转场与制作效率

范围：

- 舞台推近、拉远和平移，同时带动背景与人物，阅读 UI 保持稳定；支持复位与存档恢复。
- 按实际素材需求加入擦除等转场；模糊、色调、灰度等滤镜先验证当前渲染和性能适配，不默认绑定新的渲染依赖。
- 沉淀进场、受击、回忆等演出预设，可调参数；扩展节点预览为明确的演出试播，支持停止、复位和定位资源错误。
- 预览使用隔离状态，不能污染正式 Prefab、运行存档或编辑器场景。

验收：镜头与人物移动、震动可叠加并完全复位；不同画面比例无意外露边；预览结果与运行一致；停止试播后无音频、特效或资源残留。

## E6：未来按项目需要选装

Live2D/Spine 动态立绘、眨眼与配音口型、视频播放分别评估资源规范、插件依赖、授权和平台兼容性后实施。通过统一演出接口适配，基础静态立绘模板不强制依赖这些插件。本阶段没有默认交付承诺。

## 所有批次共同遵守的行为

| 场景 | 要求 |
|---|---|
| 历史/设置/菜单/Loading | 会话驱动的演出与相关音频暂停；关闭后按当前进度继续，不使用全局 timeScale 代替会话暂停 |
| 阅读倍率 | 剧情动作与剧情等待按阅读倍率推进；不改变音频音高；持续环境效果默认按正常速度运行 |
| 已读快进 | 有限动作立即收敛最终状态，瞬时装饰可跳过；持续效果只建立一个实例；在未读句和选项前保持正确舞台 |
| 存档 | 稳定点记录可恢复的舞台状态；尚未完成的有限动作以确定的目标状态记录，不将临时震动偏移写入；持续效果记录配置与存在性 |
| 读档 | 在 Loading 遮挡下重建稳定状态后揭幕；不重播一次性事件；加载失败不显示半套舞台 |
| 跳场/退出/重开 | 取消旧任务、移除监听、释放资源；旧会话完成回调不得修改新会话 |
| 缺图/缺效果 | 提供节点、指令与资源键定位；空图不绘制白色矩形；不会无限等待 |
| 编排与编辑器 | 参数范围校验、有效目标校验、资源引用检查；每项能力在剧情编辑器可配置，不能只留代码 API |

存档的“目标状态”是稳定点恢复约定，不等于完整倒带或过渡帧续播；动作排序和同属性接管规则必须让最终状态可确定。实施 E0 时补齐针对这一规则的数据设计与测试，再推进后续批次。

## 每批交付与记录方式

以下是各批次通用交付清单；实际完成状态以批次表与验证记录为准。

- [ ] 数据、执行、编辑入口、资源校验及兼容行为齐备。
- [ ] 按用户后续要求，将演出自然融入 LastLight 正文；不加测试段落或按钮，保留原故事、配音与分支。
