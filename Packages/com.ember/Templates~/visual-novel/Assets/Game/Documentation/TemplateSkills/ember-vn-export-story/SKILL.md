# 剧情流程回写飞书

## 准备

先检查 `lark-cli` 是否在 PATH 且 `--version` 可运行；不可用则提醒先安装并配置飞书 CLI，停止远端操作，不自动安装或改用浏览器。CLI 可用后读取当前环境的 `lark-sheets` / `lark-shared` 技能及写入/工作簿 reference（如果提供），否则查当前 `--help`；确认正确登录身份和目标权限，不输出凭据。

通过 Unity MCP 调用 `Ember.Core.Editor.EmberProjectSetup.GetTemplateSkillExecutionBlockReason("ember-vn-export-story")`，确认项目和技能身份。失败时不发布可能来自错误模板的内容。读取用户指定的**当前** Story/Chapter 资产、演出参数与来源/优化记录，而不是从聊天中的建议或旧导入表猜测已实现内容。未保存修改需要确认采用哪个版本，正式校验失败时先报告，不标为完成版流程。

确认目标链接和输出剧情范围。`/sheets/` 的“新建一页”指在指定电子表格中新增工作表页签；不是新建另一个工作簿，也不是覆盖原 sheet。若用户给的是 `/docx/` 或 `/wiki/`，先明确希望新建独立文档还是知识库子页面及落点，再使用实际可用的文档能力；不能在原正文追加冒充新页。

## 必须打开本地选择页面

完成入口只读检查后，本技能每次执行都必须生成并实际打开可交互的本地选择页面；不能只在范围不明时提问，也不能用聊天列表、静态预览或 `request_user_input_async` 代替页面。用户已给出的范围和偏好预填并保留，不重复询问。仅当用户明确要求跳过页面时按其指令处理；否则即使已授权执行，也先让用户在页面选择本批具体计划。

在本批临时目录生成 HTML 与本地回执服务，仅监听 `127.0.0.1` 随机端口；页面至少提供范围/方案选择、完整计划预览、保存草稿、明确提交和取消。服务使用随机会话令牌校验写请求，不开放跨域写入；来源文本按纯文本展示，不执行台词中的 HTML 或脚本。页面只保存选择与回执，不直接写 Unity 资产或飞书。实现文件放临时目录，不写进 Assets 或技能目录；本技能未随附页面脚本，执行时按本节实现，不能调用不存在的辅助文件，也不能直接套用图片导入专用接口。

用可保留 session ID 的终端启动服务；Windows 后台启动使用 `Start-Process -WindowStyle Hidden`，保留 PID 和日志。用客户端浏览器工具实际打开返回的 URL（Codex 可使用 `open_in_codex` 的 browser target），观察标题、选择控件、预览和提交按钮正常后，向用户发出可点击链接。打开失败就报告并修复，不能仅生成 HTML 文件便声称已展示。缺少页面运行依赖时报告实际缺项，保留只读方案，不降级为自动执行。

将范围和方案选择保存到 `draft.json`；用户可先保存范围，代理读取后补全真实计划，再刷新同一页面供最终提交。未准备完整计划、存在未解决歧义或入口检查未通过时禁用最终提交。页面提交生成 `decision.json`，至少包含 schemaVersion、batchId、skillId、projectRoot、status、choices、完整 plan、源/目标指纹和 planHash。预览后改选项必须使旧计划失效并重新生成预览；提交端校验所选项与计划一致，不把默认勾选视为提交。

只有本批 `status=confirmed` 且计划、选项和当前源/目标指纹一致时才执行。代理不得替用户点击提交、调用确认接口或伪造回执。草稿、取消、关闭页面、等待超时均不能触发写入；取消后停止本批。用户提交后回读回执，复核原有 CLI/MCP/身份条件，再执行已选计划，不另加一轮聊天许可。源数据、目标或方案变化时使确认失效，回到页面展示新计划。

等待期间保留服务，明确告知“选择页面已打开，等待提交，尚未执行”，不能把任务标为已完成；页面不保证自动唤醒代理，提示提交后回到当前任务继续。完成或取消后关闭本批服务，保留选择、回执和结果记录。

### 剧情回写页面内容

页面标题为“剧情流程回写选择”，批次目录使用 `.utmp/vn-story-export/<批次>/`。提供真实 Story/Chapter/节点范围、目标飞书链接、工作簿标题、新工作表名称，以及当前资产版本；存在未保存修改时显示来源版本选择。已有页列表只读，用于核对落点和重名，不能作为覆盖目标。

在本地构造完整导出内容后，页面展示将写入的全部流程、行数、分支去向、未实现项与验证结果，明确“在该工作簿新增工作表，保留所有原页”。按钮为“新建页并回写所选流程”。回执绑定项目资产指纹、导出内容指纹、目标 workbook 和拟用页名；提交前不得创建远端页。若改选独立文档或知识库子页面，页面必须显示实际落点及相应新建动作，不能仍显示工作表确认文案。

## 构造策划可读的新页

先在本地准备完整内容与预览，检查生成前后资产指纹一致。新页顶部写剧情名、来源页/导入范围、当前版本或内容指纹、生成时间、起始入口、验证情况。保留原五列语义，并按下列列组织流程：

`顺序 | 场景 | 说话人 | 台词 | 多语言Key | 美术 | 变化 | 步骤类型 | 目标/资源 | 参数 | 执行与等待 | 条件/去向 | 定位ID | 来源行`

- 台词从当前语言的实际文本逐字导出；不添加演出说明到正文，不改换行和省略号。`多语言Key` 列填该句的 `_textKey`（没有就留空），供策划按语言补译，导出不改 Key。旁白/内心显示标签有来源则按来源映射，实际角色 ID 另列在定位信息中。
- `说话人` 列写**真实角色名**：按角色键取 `character.<角色键>` 译文，缺条目时取 `novel_characters.displayName`。该句带 `_speakerNameKey`（揭晓前的临时称呼）时，在名字后追加 `（本句显示：<该 Key 的当前语言文本>）`，并在报告里列出本批用到的称呼 Key；**不得**把 `？？？` 当成说话人身份写回——原稿已有占位名，回写再写一次会让策划无法核对说话人，也会丢掉真实角色键。定位列始终导出真实角色键，不导出称呼 Key。
- 每个非 Say 演出命令单独一行，不把一段多个效果压成含糊的“有震屏”。“变化”用策划语言说明实际行为；参数列写真实时长、强度、颜色/透明度、缓动等，不能写建议值冒充当前值。
- “执行与等待”区分立即执行、阻塞到动作结束、并行启动、延迟和 WaitActions 绑定，注明 Cover 保持及撤幕、Flash 恢复、循环效果停止。并行效果不伪装为串行，不能简单相加推断总时长；玩家推进/分支导致的实际时长注明不固定。
- 保留选项、条件顺序、兜底路线、赋值、章节出口和结局。按节点/块分组列出分支，而不是把互斥分支拼成一条发生序列。循环用回边指向目标，不能无限展开；范围外的去向明确注明。显示当前可达/不可达状态时要有真实图校验依据。
- 原美术需求与当前实现分开：原备注保留到美术列，实际资源和效果写对应列。缺图/未实现需求写“未实现/待补”，不混为已完成。来源行不可定位则写“本地新增”，不编造飞书原行号。

## 只写新页

用经当前 CLI help 核对的 `sheets +workbook-info` 读取目标与已有页清单；建议页名 `<剧情名>-演出流程-<时间>`，同名时加唯一后缀，绝不清空或复用已有页。将目标、范围、拟用页名和完整内容预览放入本地选择页面；用户已给出的信息预填，读取有效提交后新建页，无需再次聊天确认。

使用 `+sheet-create`（当前接口支持 `--title`）新建页，保存响应中的真实 sheet ID。**所有后续写命令只能指向本次创建的 ID**，不要沿用源 URL 的 sheet query 或仅靠页名定位。写前校验目标 ID 不在创建前的页集合中。不得编辑、重命名、移动、隐藏或删除任何已有页；不回写原美术、变化列。

使用 `+table-put` / `+cells-set` 等当前 CLI 支持的类型明确的文本写入方式；所有剧情正文、ID、资源键按文本保真，前导零和 `=` 开头台词不能被解释为数字或公式。先查实际命令的 payload/选项，不手编参数。长表按有界块写入并记录进度；仅在新页设置标题、换行、列宽、冻结表头与可读的分支分组样式。

发生超时或不确定成功时先回读检查，避免重复创建新页或重复追加。将目标 workbook、创建 sheet ID、批次 ID、源指纹和已完成区间保存到本地交付记录（不含凭据）；中断恢复只续写该批创建的页，且先检查未被他人改动。失败保留可定位的未完成新页并报告，不删除原页或自动清理别人的内容。

## 回读验收

用 `+csv-get` / `+cells-get` 分段回读全体导出内容，核对行数、首尾、逐字台词、稳定 ID、分支去向和效果参数。只收到成功响应不算验收。再读取工作簿页清单，确认原页仍存在且本次写入目标始终为新 ID；不将他人并发编辑归因于本次。验证完整后交付**新页链接**、导出范围、行数、流程校验与回读结果、尚未实现的项。不要只给原文档链接并声称新页已完成。

## 多语言 Key

导出页要能直接交给翻译，因此每行都带 Key：

- 台词行的 `多语言Key` 列导出该句的 `_textKey`；选项与分流导出 `option.<storyId>.<optionId>`，
  提示与章节名同理，规范见 [多语言 Key 与配表约定](../ember-vn-import-story/references/localization.md)。
- 说话人称呼 Key（`_speakerNameKey`，家族 `speaker.<语义>`）不写进 `多语言Key` 列——那一列是句子的
  正文 Key。它按上一节的规则附在 `说话人` 列，并在报告里单独列出，供策划核对揭晓前后的显示名。
- **Key 是只读引用**：导出不改 Key、不重排、不按文本合并。Key 为空说明这句还没接多语言，
  照实留空并在报告里列出，不要编一个。
- 台词列导出**当前语言**的文本（项目未接入多语言、或该语言缺条目时就是原文），
  同时另设原文列时以资产里的 `_text` 为准，不要用译文覆盖原文列。
- 回读验收时逐字核对 Key 与台词：Key 与资产里的 `_textKey` 一致，台词与该语言列一致；
  不接受只核对行数。
## 二级步骤与文字过渡（模板 0.8.0 起）

先核对目标项目实际存在 `NarrativeStepGroups`、`NarrativeStepPresetSO`、`NovelTextReveal` 与 `HideAllCharacters`；缺少时只报告所需业务升级，不向旧项目写入无法执行的字段。参考当前 LastLight 示例与 `Assets/GameResource/Authoring/Narrative/StepPresets` 的实际自定义步骤资产。

二级步骤是连续基础命令上的 `StepGroupId / StepGroupName / StepGroupColor` 编辑分组，运行仍执行基础命令。通过 `Game.Narrative.Editor.NarrativeStepGroups.GroupRange(node, start, count, label, color)` 原位包装（索引从 0 起），保留原 command/line/action ID；新副本使用 `Wrap(commands, label, color)` 再 `Insert(node, index, commands)`。Wrap 自动重建命令、台词、动作 ID 及内部 WaitActions 引用；组合外等待引用必须补全选区或明确处理，不能伪造完成。人物实例 ID、变量、资源键不会自动替换，要按插入路径的真实状态核对。

内置组合由 `NarrativePresentationPresets.Build` 生成：进场、受击、回忆、镜头/遮罩复位、隐藏所有立绘、恢复舞台状态、场景收尾。HideAllCharacters 同时渐隐包含自由位置的全部人物并释放其动作/绑定效果；场景收尾不清空剧情变量、不停止音乐，也不承诺清除所有粒子。自定义步骤是 NarrativeStepPresetSO 中的命令快照，插入后独立，不因修改资产而自动改变既有剧情。

章节卡 Say 支持 TextReveal（Default/Typewriter/Fade/Instant）、TextFadeDuration、TitleExitDuration、TextSpeedMultiplier、TextEase。默认章节卡文字渐显，其他正文为打字机；点击未完成文字先补全，再次点击等待章节卡渐隐结束才推进。进入/退出时长 0–30 秒，速度倍率 0.05–20；暂停冻结，已读快进收束。不要用附加 Wait 或 Cover 重复模拟已经由章节卡自身管理的退出渐隐。

导出为每个连续组增加“二级步骤名称 / 组ID / 组内顺序”列；可先列组合摘要，但仍逐条导出实际基础命令，不能用组名代替内部效果、赋值和等待。自定义预设以节点当前插入副本为准，不以可能后来修改的预设资产替换流程。章节卡输出文字入场方式、渐显时长、打字速度倍率、退出渐隐时长与缓动，注明“完成文字后点击，等待渐隐结束才进入下一步”。组颜色可用于新页行样式，不影响原台词或原页。来源映射缺失仍标记本地新增。
