# 视觉小说 UI 皮肤制作

使用项目中的 `Game.UI.Editor.NovelUISkinEditorService`；窗口入口为 `Ember/视觉小说/UI 皮肤编辑器`。窗口与 skill 共用创建、替换、参数保存、剧情关联和预览接口。

## 开始

核对目标 Unity 项目与 MCP 实例。调用 `Ember.Core.Editor.EmberProjectSetup.GetTemplateSkillExecutionBlockReason("ember-vn-edit-skin")` 检查技能有效身份；非空时报告原因并停止写入，不能靠目录存在跳过。读取本项目规则和 [操作接口](references/api.md)。若 MCP 不可用，可检查图片和准备映射，不能声称已完成 Unity 导入或画面验证。

只处理用户指定图片和皮肤。查看每张图片内容、尺寸、透明区域，结合皮肤条目的页面、控件、相对节点与页面预览选择用途，不仅凭文件名匹配。目标明确时直接处理；有多个合理匹配时问清目标控件后再写入。不把剧情背景或立绘当成 UI 皮肤素材。

## 制作

- 创建时用 `Create`，来源可选基础外观、现有皮肤资产或旧配表皮肤。新皮肤是独立快照，来源变化不会自动传递。用户要求编辑现有皮肤时不另建副本。
- 先读取 `skin.Images` 的真实 `Key`，建立文件到目标的映射；调用 `ReplaceImages` 批量导入。外部原图保留，所有新图片由服务复制到目标皮肤内部。不要覆盖原皮肤、直接改源 Prefab、Binding、配表 bytes 或生成代码。
- 调用 `SetAppearance` 调整显示类型、九宫格边距、像素比例、保持比例、颜色与透明度。边距按左、下、右、上，以图片像素为单位。先看边框结构再设九宫格；背景、图标和面板不套同一组参数。多 Sprite 资源需换为独立图片后才能调整边距。
- 图片像素编辑或生成仅在用户明确要求时执行，使用可用图片工具；通常通过导入和显示参数解决。位置、锚点、字体及页面结构属于布局编辑器范围，需要时明确说明额外改动。
- 创建/替换不自动分配剧情。只有用户要求应用到指定剧情时调用 `Assign`；传 null 皮肤表示该剧情明确恢复基础外观。未分配的旧配表皮肤继续兼容。

## 视觉检查与交付

用 `NovelUISkinPreview` 导出受影响页面的修改前后 PNG 到 `.utmp/novel-skin/`，实际打开图片查看。至少检查 1920×1080 和 1440×1080 下的拉伸、裁切、九宫格边缘、文字遮挡及对比度；只检查受影响页面及实际可见状态，不把未渲染的隐藏弹窗声称为已检查。必要时调整并重新渲染。

执行 `Validate`，区分缺失引用等错误与九宫格无边距等提示。报告目标皮肤、替换控件、仍待替换项、实际查看的页面和未验证部分，并给出截图位置。保留 Undo 和旧图片供回退，不自动清理用户资源。模板作者修改在 Assets 中完成，之后按项目正式 SaveTemplate → Bump 流程交付。
