# topdown-2d 俯视起点

本模板与 platformer-2d 平级，直接继承 base。提供正式启动、二维移动与独立瞄准、实体墙碰撞、独立武器状态机、近战与移动射击、冲刺、敌人、受击死亡、暂停、保存继续、检查点及制作工具。提灯、污染、产品角色和剧情由消费项目实现。

从 `Assets/Game/Scenes/FrameworkScene.unity` 进入 Play，等待主菜单后选择开始或继续。不能直接运行 GameplayScene 代替正式初始化。

| 输入 | 键鼠 | 手柄接线 |
|---|---|---|
| 移动 | WASD | 左摇杆 |
| 瞄准 | 鼠标世界落点 | 右摇杆，死区后保留上次方向 |
| 当前武器攻击 | J / 鼠标左键 | 西键 |
| 切换武器 | Q | 左肩键 |
| 冲刺 | 左 Shift | 右肩键 |
| 交互 | E | 南键 |
| 暂停 | Esc / HUD | Start |
| Focus 扩展示例 | F，仅竞技场方案装配 | 北键 |

手柄表项表示已装配绑定；模拟设备与真实设备验收分别记录。当前占位美术用颜色、方向标记、刀光和敌人预告色表达行为，可从角色方案配置 1/4/8 向序列帧。

默认训练剑挥击时锁移动/朝向；按Q切换训练手枪，可边走边瞄准、单次按键射击。手枪是即时射线白盒，先被实体墙截断，再命中最近敌人，黄色短暂射线表示本击范围；不包含实体弹丸、弹匣或掉落系统。武器各自拥有独立图和资源，切换会取消旧武器动作，不退款，也不重置冷却/次数。

训练场从原点出生；下方青色方块是检查点，接近后按 E 切换持久状态并更新检查点。敌人接近后变橙预告，再出手并恢复。死亡后 HUD 可读档或重试。训练沙袋和敌人均有稳定对象身份。

HUD 使用 EUI 开发中心生成的 `EUITopdownHudPage`。默认槽位 0；保存允许待机/移动，攻击、冲刺、受击、死亡和不支持恢复的 Owned 效果会明确拒绝。保存退出失败留在当前会话，失败写入结果可在显示原因后明确确认。退出按钮等待已接受的存储操作。

主菜单“继续”读取同一槽位并校验，不把坏档当新游戏。正式存储配置为 `TopdownProgress / ember.topdown2d.progress`。关卡工作台试玩使用独立 `Library/TopdownTrials/<request>`，不读写正式进度。

编辑器扩展的启用、版本签收和操作文档从项目中心“扩展组合”发现；模板默认声明在 `Assets/Game/Config/EmberExtensionDefaults.json`。俯视参数/观察源/适配器还须正式模板及 Player 模块条件，残留脚本不授予访问。关闭后方案、关卡与草稿保留；房间地图组合默认关闭，需要项目接线。公共管理与迁移说明见[框架扩展迁移](../../../../Packages/com.ember/Documentation~/manual/composable-extensions.md)（本地未发布，普通保存与 Bump 分别处理）。
