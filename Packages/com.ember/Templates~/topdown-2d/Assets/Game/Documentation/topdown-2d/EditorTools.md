# 俯视玩家编辑工具

归属 `topdown-2d`；本操作文档从项目中心的已启用扩展索引发现。需要正式模板身份、匹配的版本/hash、`ember.fsm.blueprint` 及启用的 Player 模块。公共术语和扩展管理说明仍从框架 Wiki 阅读。

统一入口为 `Ember/Player/玩家开发工具`。选择既有角色方案后编辑真实序列化参数；“复制为独立方案”复制可变方案、角色图、Definition、能力和武器配置，美术引用仍共享。目标必须为 Assets 内尚不存在的新目录，不能覆盖旧方案。

“打开状态机蓝图”及各武器蓝图使用公共蓝图窗口。俯视参数/观察源只在本模板体系与 Player 模块有效时登记；角色状态机和武器状态机分别拥有自己的图与会话，不由窗口额外 Tick、评估输入或提交技能资源。

运行中的会话使用准备时捕获的方案副本，编辑源方案只影响之后的新会话。窗口的本地攻击方向只用于范围预览，不改变场景坐标或运行中的武器方向。

关闭扩展或切换模板/版本后，旧窗口停止操作并保留方案引用、新方案目录、方向和其他草稿。重新启用同一版本可恢复；版本/hash 变化后从正式入口打开当前版本窗口，旧窗口不会自动接管新版本。

关卡制作文档也由项目中心按其扩展与模块条件提供。正式试玩另需 `ember.level.trial`，复用既有试玩会话与独立开发存档；它不要求额外开启 FSM 蓝图。模板普通保存、Bump、提交与发布分别处理。
