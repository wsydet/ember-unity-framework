# 玩家 Ability / Skill 适配

归属 platformer-2d；Entity/Powers 提供宿主中立的资源基础，Player/Powers 负责玩家开放、落地补充和进度适配。完整配置与冻结、保存/恢复边界见[玩家架构](../../../Documentation/platformer-2d/PlayerArchitecture.md)。文末测试数字是历史证据，不表示本文本轮重跑。

PlayerAbilityDefinition / PlayerSkillDefinition 继承 Entity 配置基类，保留玩家有效地面支撑补充标记；稳定 ID、默认开放、次数、CD 只在公共基类维护。PlayerPowerConfig 继承公共装配配置，可引用公共或玩家派生定义。

PlayerPowerSession.CreateNewGame 将公共默认开放解释为新游戏默认解锁，并捕获需要地面补充的资源。PlayerPowerProgress 提供玩家解锁视图，读取同一份独立开放数据，不复制第二份真值。它不是存档格式，不提供旧档默认值或迁移。

Abilities / Skills 返回 Entity 层资源入口。Query、TryCommit、SetOpen、RefillUses 的基础契约见 [Entity 说明](../../Entity/Powers/README.md)。玩家适配内部 Tick 接收游戏秒数；RefillGroundUses 只补充配置指定项，不清 CD 或改变解锁。

Controller 准备时使用完整方案捕获的 Powers 创建每宿主独立资源，未选装时创建空容器。Context 暴露 Abilities/Skills/PowerProgress；候选和模块持有同一独立解锁视图。PlayerModule 唯一驱动 Controller.Tick，使用游戏秒推进 CD；FixedTick 仅在 PlayerJumpWindow 确认首次有效支撑时于状态处理前补充资源。连续支撑不重复补充，向上近地不算支撑。暂停不推进，准备失败、取消及角色停止清理资源。

正式 v2 快照保存并恢复开放数据、剩余次数和 CD；不再按“非空能力装配”禁止保存。旧 v1 或能力集合不匹配明确拒绝并保留旧文件，不补默认值。恢复从完整快照和冻结配置重新建立资源，不回配置出生点清零。

## 二段跳

正式 PlayerPowers 装配稳定 ID `air-jump` 的 Ability，示例启用、默认解锁、上限 1 次。项目是否启用由装配槽位控制，新游戏默认开放来自能力定义；当前会话解锁和剩余次数来自各宿主的资源实例，存档恢复不会以默认开放覆盖已保存值。AirJump 是 Air 下独立状态，进入时提交一次资源消耗并消费一次起跳请求；按住不重复触发。普通地面、土狼与落地缓冲起跳优先。

仅普通 Jump 真正消费有效起跳请求时，将二段跳次数补到配置上限。单纯落地、恢复上升路径、二段跳自身均不补充；耗尽后落地再走出平台，仍无二段跳次数。此能力禁止启用 `RefillOnGroundSupport`，其他能力的地面补充规则不变。

运动参数唯一归 PlayerJumpFeel：竖直速度（u/s），进入时保留实际水平速度或设置朝向速度（u/s）。运行实例使用准备时复制的 PlayerFeelRuntime。二段跳不使用普通 Jump 的短跳及持续早期水平接管，进入后恢复普通空中控制。蓝图右侧提供真实参数及装配字段，装配变更在新会话生效。

新增装配后，旧 v2 空能力集合不再匹配，严格拒绝恢复并保留旧档，不迁移、不补次数或默认解锁。同装配快照完整恢复剩余次数；恢复上升时不会再次施加二段跳冲量或补满资源。

## 墙面动作

`wall-slide` 与 `wall-jump` 独立装配、独立解锁，正式示例启用且不限次数。空中非上升、检测到有效墙面且持续朝墙输入时墙滑；松方向、反向、失墙或落地退出，向下输入切换快速墙滑。普通地面/土狼起跳优先，其次接触墙面的踢墙跳，最后二段跳；墙跳可在上升时使用，不要求先墙滑、不提供离墙土狼机会，也不补二段跳。

PlayerJumpFeel 的墙面参数由蓝图右侧独立分组编辑：慢/快滑速度、墙跳水平/竖直速度（u/s），离墙保护与后续回墙窗口（游戏秒），回墙开关和倍率。每宿主 PlayerWallMotion 持有原墙方向和计时。保护期间保持离墙水平速度且禁止重入墙滑/墙跳；随后回墙窗口内朝原墙输入首次将竖直速度清零，回墙期间水平为朝墙空中速度乘倍率，重力为基础重力乘倍率平方，结束恢复常规规则。

普通跳、二段跳和落地清理旧墙跳控制，整体暂停不推进窗口。读档只恢复速度与能力资源，不续接墙跳窗口或重复发射。新增能力集合仍采用严格匹配，旧缺项存档不会自动迁移或补默认值。动作经统一 Motor 执行，没有新增独立 Update。

白盒窗口提供墙面区试跑入口，测试区位于 x=12—24，含双墙和墙顶角；正式 GameplayScene 不包含这些测试几何。键盘操作需 Game 视图取得输入焦点。蓝图诊断展示左右墙身份、竖直输入、墙滑状态和两个窗口的剩余秒数，不重新执行条件或消费输入。

Tests/Fixtures/Powers 三个 SO 的原脚本 GUID 和资产 GUID 保留；继承字段迁移、强制重新序列化和重新导入已验证，GUID 保持不变。原 19 项资源测试已适配公共接口并通过；当时组合回归为 107/107，包含 4 项非玩家宿主测试。




## 地面与空中冲刺

PlayerInputAdapter 显式绑定可选 Dash Action；与跳跃分开消费，按住不连发，首次物理决策后未使用请求清除，暂停禁用时不累积。地面和空中冲刺是独立 Skill/解锁/CD；是否启用及资源来自 Powers，速度和持续游戏秒数来自 PlayerMoveFeel。动作进入一次提交并锁定方向，跳跃优先；撞墙、地冲离地、空冲落地等按真实状态规则中断，已提交资源不退还。

运行使用完整方案捕获值，不修改共享 SO。保护和尾随唯一由方案 ActionEffects 提供：动作持有 Owned，正常结束释放后可创建独立 Timed 尾随，中断无尾随。动作中拒绝保存；可恢复尾随按接受时剩余时间恢复，不重新开始冲刺。运动模式、参数、能力和效果分别配置，不用默认初值推断已启用。

## 踩头反弹

`head-jump` 是独立 Ability，正式示例启用、默认解锁、不限次数；默认不按落地补充资源。实际可用性还要求下降从上方穿入显式 `EntityHeadTarget2D` 区域、有效跳跃请求、无地面/土狼起跳资格。优先级为普通起跳、踩头、踢墙跳、二段跳、冲刺。成功 Enter 提交一次能力并消费请求，保留实际水平速度、按 Jump SO 的 HeadJumpSpeed 赋向上速度；不使用普通短跳、不返还二段跳、不伤害目标。

每宿主 EntityHeadProbe2D 由 Controller 物理步采样脚底路径；初次重叠、侧入、向上穿入以及区域内迟按不触发。同一次穿入只提供当步候选，离开后重新从上方进入才可再次触发。首版只支持静止、轴对齐的 BoxCollider2D Trigger，标记与 Collider 位于同对象；目标移动、变形或使用动态/运动学刚体时不接受。此标记不代表敌人或战斗系统。

冲刺、下穿、挂边/翻越、落地停顿、翻滚期间不检测。整体暂停冻结；HeadJump 活动时拒绝保存，上升结束转 Fall 后可保存。停止与恢复清理旧目标，读档只恢复已有快照状态，不续接反弹、不重复提交。增加能力装配后，缺少该能力的旧快照仍严格拒绝，不自动迁移。

独立白盒 x=100—120 为踩头区，x=110/116 紫色静止目标上方的青色 Trigger 是检测区域；需下降到区域时新按跳跃。提前按下可能按优先级使用二段跳。蓝图从正式图读取状态，HeadJump 和速度参数来自正式实现；图节点数量不是扩展限制。
