# UI 皮肤制作

打开 `Ember/视觉小说/UI 皮肤编辑器`。

1. 展开“创建新皮肤”，填写标识与名称。来源可选当前正式 UI 基础外观、已有皮肤资产；安装了旧配表皮肤的项目也可选旧皮肤。复制配置和素材后形成独立快照，来源以后变化不会传递。
2. 选择页面与图片位置。拖入项目图片或外部 PNG/JPG/TGA/PSD，为多个位置逐一指定后点击“应用批量替换”。原文件保留，新图复制到该皮肤内部。
3. 调整显示方式、保持比例、颜色/透明度、九宫格像素边距与比例，点击“保存显示效果”。边距顺序为左、下、右、上；多 Sprite 图集请先换为独立图片再调整边距。
4. 在 1920×1080、1440×1080 等尺寸下检查，使用“对比基础外观”或导出 PNG 比较。列表可只显示“待替换”，原图也可明确标记保留。
5. 选择剧情后“应用此皮肤”，下次打开页面生效；“恢复基础外观”清除该剧情的覆盖。仅创建和编辑皮肤不会改变剧情关联。

## 资源与兼容

- 每套皮肤：`Assets/GameResource/Resources/UI/Common/Atlas/NovelSkins/<id>/Skin.asset` 与 `Images/`。
- 剧情关联：`Assets/GameResource/Resources/Config/Narrative/UISkinAssignments.asset`。
- 新皮肤资产保存图片引用和显示参数，不复制页面 Prefab、代码或 Binding。控件位置、锚点、字体与结构仍由布局编辑器管理。
- 已安装旧 `NovelSkin` 配表系统的消费项目：明确的皮肤资产关联优先；没有关联的剧情继续走旧表。旧表作为复制来源，不同步回写，也不形成两份维护源。
- 包含主菜单、阅读页、阅读菜单、历史、字号、选项、存档及存在时的姓名输入页。剧情立绘/背景及其资源归剧情系统；不将它们作为 UI 皮肤占位素材。
- “检查皮肤”报告失效目标、重复目标、外部共享图片和丢失图片等；九宫格未设边距会提示检查。
- 配置修改支持 Unity Undo；旧图片保留用于回退，不自动删除未引用素材。

## 自动化

模板技能 `$ember-vn-edit-skin` 使用与窗口相同的 `NovelUISkinEditorService`，负责查看指定图片、映射目标、替换和渲染检查。具体接口见模板技能的 `references/api.md`。图片含义不明确时先明确目标控件。

新增页面需加入服务的页面清单，并在正式页面/Item 的初始化接入 `NovelUISkinRuntime.ApplyCurrent`；新页面与绑定仍由 EUI 开发中心创建。仅添加清单不会自动给页面接线。

## 维护与验证

`NovelUISkinTests` 覆盖副本独立、导入设置不影响源、非法批次无写入、替换撤销、切换恢复和参数边界。真实页面还需检查复制后的内置图片、不同分辨率和运行期显示。

模板作者修改 Assets 后通过正式保存与 Bump 发布。消费项目可以先迁移这组独立业务文件使用编辑器；模板技能的受管发现副本需通过模板技能更新入口安装。不能仅靠复制 SKILL.md 冒充已完成模板技能登记。
