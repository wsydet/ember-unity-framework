## 五列格式

用户截图为 `场景、说话人、台词、美术、变化`。明确处理合并场景续行、空说话人、内心旁白、美术备注、空行、纯演出行及范围外跳转。截图用于结构确认，不代替远端文本读取；正式导入范围由用户指定，不默认整表。

例如第 16 行只有美术列 `fade out`，应识别成演出要求并确认具体语义，不丢弃、不生成空台词；第 13 行台词中的括号文字默认保留，不自行改写为动作；空说话人的叙述不能直接继承前一个角色。优化阶段不会为“闷热”等叙述添加未出现的下雨或打斗；回写阶段将原美术需求和已实现效果分开说明。

## 待执行验收

以下是真实行为验收清单，不是已通过的测试结果。使用隔离项目和专用飞书测试工作簿。

| 场景 | 预期 |
| --- | --- |
| CLI 缺失、不可执行、未登录或无权限 | 分别报告原因；缺 CLI 要求安装后继续；无资产或远端写入 |
| 选定一个中间范围，含合并场景与正文内换行 | 只导入所选行，必要上下文不导入；原文、标点和真实换行保留 |
| 空说话人、内心旁白、未知美术、fade out | 给出具体映射选择，未解决歧义不静默提交 |
| 重复导入、源表插行、重复台词、本地已优化 | 无变化不写入；稳定映射可追溯，无法唯一匹配时阻断；不抹除优化 |
| 多分支或跨章跳转 | 保持条件、选项顺序、兜底和去向；范围外目标明确处理 |
| 震屏/闪白/渐变优化 | 核对现有效果与资源；台词及逻辑保持项逐项一致；遮罩撤幕、动作等待和分支汇合可运行 |
| 优化后导出 | 当前真实参数逐命令展示，并行与等待明确；台词逐字一致，分支不扁平化 |
| 新页同名、CLI 超时或部分写入 | 新建唯一页；凭真实 sheet ID 续传，不改原页、不重复追加；回读全范围 |
| 任一步本地失败或预览后变化 | 停止、保留备份、复核指纹，不覆盖用户并发修改 |

部署前先补齐消费端正式编辑 API 兼容及测试，再审查模板差异，经正式 SaveTemplate → Bump 封存；后续框架发布按仓库流程单独授权。完成这些前，不向用户承诺新项目的一键导入/优化已验证。
