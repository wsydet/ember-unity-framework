# 内容工具

- `Ember/视觉小说/图片资源管理`：小说模块启用时出现；旧的“立绘管理”入口打开同一窗口。左侧 Odin 分类树，中间按组显示缩略图，右侧查看和编辑。内置立绘、背景和表中的皮肤图片；不会把音频的 `resourcePath` 当成图片。
- `Ember/多语言中心`：所有模板共用。选择“公共 UI 文案”“小说 UI 文案”或“小说剧情文案”，搜索、修改或新增 Key，然后保存更新。翻译按钮提供源语言、目标语言、生成预览及应用草稿；需配置自己的兼容服务。

通用多语言代码由框架提供，小说只负责 `novel_ui_text` / `novel_content_text` 的注册与强类型表适配。
既有剧情、UI Key 和存档格式保持不变。旧语言偏好在首次访问时迁移到通用语言偏好。
图片编辑写回对应源表并烘焙；新增角色应先维护角色表。
多语言完整说明见包内 `Documentation~/manual/localization-center.md`。

## 图片操作

1. 选择分类。立绘按角色自动分组，皮肤图片按皮肤和页面分组；背景可自建多级文件夹。已有但尚无立绘的角色也显示在分类树中。
2. 填写“新 Key”并点“新增图片”。右侧可修改角色、表情或皮肤页面等源表字段。
3. 拖入项目图片，或点“从本地导入 / 替换图片”。本地导入支持 PNG、JPG；图片先进入草稿，保存时才复制进所属模块的 Atlas 子目录。替换保留 Key，多个 Key 仍可绑定同一张图。
4. “保存当前表”写回该来源的源表并烘焙运行数据。图片缺失、引用无效、源表被外部修改或烘焙失败会阻止保存；本次新导入的图片会撤回，草稿保留以便修正。切换分类不会丢弃草稿；关闭窗口可保存所有表或放弃。

皮肤图片按 Sprite 加载。已有项目图片需设为 Sprite / Single；导入新图片时由面板配置。面板不修改既有图片的导入设置，也不负责皮肤九宫格和控件位置；这些仍在皮肤编辑器中调整。

## 文件夹与批量整理

在分类树选择角色、皮肤页面或背景分类，输入文件夹名创建空文件夹。名称可使用 `服装/日常` 这样的多级路径。点击缩略图选择，Ctrl / Cmd 多选，再在右侧选择目标文件夹，或创建文件夹并移入。

文件夹是逻辑目录，不移动磁盘图片、不修改资源路径或剧情 Key。多角色批量整理时，分别写入各自角色下的同名文件夹。目录立即保存并支持 Undo，位置为 `Assets/Game/Module/Narrative/Editor/Layouts/ImageFolders.asset`，应与项目一起提交；它不属于运行数据。修改角色后按新角色重新归类，不继承旧角色的手工分组。

## 接入其他图片表

在项目的 Editor 目录使用 `Create → Ember → 图片资源来源` 创建来源资产，填写分类名、表 ID、主键列、图片路径列、自动分组列、加载类型及导入目录，然后在面板点“重新加载”。同一张表的多个图片字段可分别登记，草稿共享同一源表并一起保存。不同来源可以有相同 Key，分组信息互不覆盖。

此入口管理明确登记的 Resources 图片列；无法静态发现任意代码拼接的 Key。新表完成登记后进入该面板，固定 Prefab 引用不会自动收录。
