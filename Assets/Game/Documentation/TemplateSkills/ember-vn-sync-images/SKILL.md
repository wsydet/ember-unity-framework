# 视觉小说图片分类与统一导入

唯一维护源属于 visual-novel 模板。执行前读取项目规则，通过 Unity MCP 核对实际项目并调用 `Ember.Core.Editor.EmberProjectSetup.GetTemplateSkillExecutionBlockReason("ember-vn-sync-images")`，同时检查下述两项依赖技能。非空原因停止业务写入并指向项目中心的模板技能预览/同步；无 MCP 只准备草稿，不能启用确认。支持正式继承技能的派生模板。

## 分类与计划

读取同级 `ember-vn-import-images/SKILL.md` 及其项目映射、`ember-vn-replace-images/SKILL.md` 及其确认说明，复用两者的分析、配表、引用保护和验证流程。本技能是统一确认入口，不另建图片写入算法。

只扫描用户指定的一个图片文件或目录（含子目录），实际查看源图及项目候选旧图。若用户给出多个路径，分别枚举后扩展扫描适配，不擅自扩大到共同父目录。比较内容 SHA256、实际像素、角色、表情、服装、姿态、昼夜、路径、配表与引用：

- 新增：没有对应旧资源，建议立绘、背景或其他用途，并准备角色、剧情、变体与资源键。
- 更新：找到同一语义及差分的旧图，准备候选、理由、全部已知引用影响和导入设置限制；不按相似度自动覆盖。
- 同内容：说明已有资源及绑定，可选择复用或无需修改；不能因文件名不同重复导入。
- 待核对：多候选、无法看图、用途不明或导入条件不支持，默认跳过并说明原因。差分独立保留，不将整组表情当重复图。

## 一次确认

使用 [统一确认服务](references/workflow.md)。同一页面逐图选择“新增 / 替换 / 跳过”，显示源图、候选旧图、理由、差分警告及引用；新增填写下层导入技能需要的字段。AI 分类只是页面建议。页面预览合并两项原技能实际生成的计划，阻止跨组目标冲突。用户一次点击“确认全部”授权整个固定计划。

实际打开本地 URL 并检查图片和控件后交给用户；不代替用户提交，不调用 confirm 接口或制造回执。未提交保持等待，取消是终态。不要另外启动两项下层确认页面。统一回执只适用于本技能编排，不能冒充下层独立回执。

## 调用与执行

首次业务写入前运行统一 `verify`，同时重新通过三项技能的 MCP 身份检查。按回执的 `plan.imports` 调用新增技能“确认后执行”，按 `plan.replacements` 调用替换技能“执行与验证”；跳过项不执行。两项技能的统一确认委托条款允许复用该回执，无需再问用户。调用指在当前代理流程中读取并执行对应技能，不要求创建子代理。

先备份两组全部受影响文件、meta、源表及烘焙产物，保留每项输入/输出指纹和执行日志，再执行替换、执行新增配表并烘焙。统一 verify 仅在首项写入前运行；本批自身改动后不拿旧基线重验另一组。中途失败停止后续组，只恢复仍匹配本批输出指纹的文件，保留并发修改并报告恢复项。统一回执不提供跨资源与配表的天然事务；不得无记录重复消费。

新增保留外部原件，替换保留旧路径、meta、GUID 和表键。范围外新目标、源图变化、外部并发修改或新风险使原确认失效：只重新确认受影响的变更，不重复要求已完成且未变化的项目；不得静默扩大授权。逐图报告新增、替换、复用、跳过或失败及原因、引用影响、备份、配表烘焙和实际 Unity/画面验证范围。

模板作者只编辑 Assets 源，经正式预览/同步进入发现目录，SaveTemplate → 显式 Bump 才能分发；不手改发现副本、模板快照、安装指纹或 hash。
