# 章节内跳转与复合流程

本能力自 visual-novel **0.18.0** 提供，**0.18.1** 收束使用与兼容文档；存档格式仍为 9。核心位于 `Assets/Game/Module/Narrative`，保存接入位于 `Game/Module/NovelSave` 与 `Game/UI/Runtime/Module/NovelSave`，试播位于 `Game/UI/Editor/Narrative`，均属模板业务层。不增加框架 Manager，不包含消费项目数值或私有剧情。模板封存、框架发布、消费端部署是三个独立步骤。

本页是成对跳转、流程调用、变量和存档边界的使用说明；[模板首页](visual-novel/README.md) 提供版本与验证摘要，[作者指南](visual-novel/Authoring.md) 提供普通剧情与演出编写入口。旧 [设计记录](visual-novel/Design.md) 中的首版范围不代表当前能力上限。

## 编写流程

| 节点 | 入口与出口 | 用途 |
| --- | --- | --- |
| 跳转点 Jump | 只有输入 | 按接收点稳定 ID 跳转，不画长回线 |
| 接收点 Receiver | 只有后续输出 | 多个跳转点共用一个接收位置 |
| 流程调用 FlowCall | 输入 + 命名结果输出 | 调用本章流程，每个调用点独立配置返回后续 |
| 流程开始 FlowStart | 只有后续输出 | 定义入口及局部变量，通过调用节点进入 |
| 流程结束 FlowReturn | 只有输入 | 返回结果名，由当前调用栈决定返回位置 |

在剧情图按空格，创建跳转点、接收点、复合流程调用、流程开始或流程结束。节点设置中可设置“所属流程”；留空表示章节主线。流程开始自动属于自身，不应再设置上层流程。嵌套关系由调用节点表达。

接收点只有后续输出。跳转点只有输入；右键跳转点，在“关联接收点”中选择同作用域接收点。保存的是接收点的稳定节点 ID，资产名称只作展示。多个跳转可关联同一接收点。右键可定位目标、列出全部来源、切换关联线显示；关联线只读，不是执行图的直连输出。

流程开始声明每次调用的局部变量，并连接流程首节点。内部普通节点和流程结束均设置同一个所属流程。主线上放置调用节点，选择流程，并为每个返回结果配置后续。默认结果为“完成”，可以使用“取消”“成功”“失败”等名字，按区分大小写的原文匹配；重命名结果时须同步每个调用点。

右键流程开始、调用点或内部节点，可以进入独立视图、折叠/展开流程、选择整个流程后一起移动。通过“流程视图/显示主线与独立区域”退出独立视图，切换章节会清除旧流程筛选。折叠信息与位置存于编辑器布局资产，支持 Undo/Redo，不参与运行指纹。独立视图中新建的节点会归入该流程；创建另一个流程开始不会改变现有流程归属。

选择流程开始再复制会复制全部内部节点，生成新的节点、命令、台词 ID，并重映射内部直连、跳转目标、流程归属和选中的调用目标。单独复制调用点仍调用原流程；单独复制跳转点仍关联原接收点。只复制部分内容时，指向未复制资产的外部引用保持原意；校验会拒绝跨作用域连接。删除接收点清空来源关联，删除流程开始使调用目标失效；选择整个流程删除可一起移除成员，撤销恢复引用。被移除的独立资产文件遵循原图编辑器策略保留。

## 运行边界与变量

普通跳转仅限同一章节、同一流程作用域，不初始化变量，也不创建/释放调用栈。不能跳入流程或跳出流程返回到主线。普通直连同样不能跨作用域，流程开始和接收点没有直连输入。

调用创建独立栈帧，流程结束按本次调用节点的结果出口返回；嵌套最多 16 层，禁止直接或间接递归。内部 Ending 和 ChapterExit 均非法。调用栈、返回映射和变量由执行器管理，自定义步骤不能代替位置管理。

变量继续使用 `NovelValue`/`NovelVariable`，现有 Global 与 Chapter 枚举数值不变，新增 Flow：

| 数据 | 所有者 | 生命周期 |
| --- | --- | --- |
| 持久玩家数据 | 现有 PlayerDataModule / 项目自己的持久化模型 | 项目定义；模板中的 PlayerDataModule 默认关闭 |
| 剧情全局变量 Global | NovelStory / NovelCheckpoint | 跨章，随小说存档，不等同于跨存档玩家数据 |
| 章节变量 Chapter | NovelChapter / NovelCheckpoint | 进入章节初始化；普通跳转不重置 |
| 流程临时变量 Flow | 当前栈帧 | 每次调用独立初始化，返回释放；只访问当前帧，不能隐式访问父帧 |

不自动镜像 PlayerData 的金币到剧情 Global。消费项目须选择一个权威数据源，已有持久玩家属性通过原模块接口使用；若要在剧情条件中消费它，应定义明确的同步/事务边界，不再造一套持久数据源。月份、步数仅是示例章节变量，收益与法力等数值规则由消费项目定义。

赋值、运算、随机整数、条件、正文绑定和自定义步骤结果均支持当前流程作用域。流程变量用于说话人称呼时，历史保留当次调用值；返回后不会读取下一次调用的同名变量。

## 存档与兼容

存档格式 9 保存当前节点与稳定指令 ID、计时等待剩余时间、调用栈、调用节点 ID、每个命名结果的返回目标、每帧局部变量和随机状态。恢复只接受新的运行器，在恢复点直接重建状态，不重新执行调用、赋值或随机指令。输入仍使用会话代次、位置版本和帧号防重，旧会话回调失效。

可以在内部选择、已完整显示的对白、正数计时等待中保存。打字中继续沿用“完整显示后保存”策略。普通自定义步骤、名字输入和小游戏没有通用的外部状态序列化协议，执行期间拒绝保存，并报告章节/节点/指令位置；完成后回到支持的稳定点再保存。不能声称恢复任意小游戏。

演出仍沿用原会话策略：进行中的可记录动作在快照中归一到目标状态，短暂效果/音频按既有规则恢复，并非逐帧还原；BGM 段落迁移固定以格式 8 为边界。计时等待精确恢复剩余时间，但不承诺与进行中的并行动画逐帧同步。

旧节点枚举值不变，缺省所属流程为空。没有新流程字段的剧情保持原语义指纹字节流。格式 8 存档保留原随机状态；更早的含随机剧情存档仍按原规则拒绝。旧存档没有调用栈，只能恢复到主线。名称、布局和折叠不影响指纹；节点归属、跳转目标、调用目标、结果出口、流程变量声明和执行指令改变会改变指纹。语义不一致时拒绝恢复并保留原文件，错误包含章节、节点和指令 ID；不会猜测新返回位置。

## 诊断与示例

校验涵盖节点 ID 重复、目标缺失、结果缺失/重复、跨作用域直连或跳转、内部非法结束、递归与深度。确定的无等待直连闭环静态报错；依赖条件或调用返回的循环保留运行时即时执行步数保护，达到上限产生可定位错误。对白、玩家选择和正数计时等待可以形成正常循环。

运行观察显示章节、调用链、当前节点与局部变量，可定位调用点及各结果返回位置。跳转来源通过接收点右键查看。

图编辑器“连续试播”从选中的主线节点继续执行；选择内部节点或流程开始时，从所属流程入口建立一次独立调用，任意结果返回后结束试播。沿用正式 NovelSession、资源和自定义步骤预览策略，状态栏提供选项和执行路径定位。所有剧情资产克隆为临时副本，起始变量不写回原资产，窗口不写存档。“播放节点”仍对普通对白提供单节点演出试播，对新流程节点执行连续试播。

示例入口：`Ember/Novel/创建日程与子流程示例`；正式资产路径为 `Assets/GameResource/Resources/Config/Narrative/FlowExample/Story.asset`。月份从 1 开始，每月 3 步，共 2 个月；两处调用复用行动流程。完成统一推进，取消不推进，月末结算后换月。示例不加载外部图片、声音或产品剧情，不修改默认启动剧情。

打开示例 Story，在图中选择“每日分流”并点击“连续试播”，即可检查选择、取消与换月；要检查正式存读档，按 [从指定入口试播](visual-novel/Authoring.md#从指定入口试播) 从 Play 主菜单启动该 Story。示例已经存在时创建菜单复用原资产，不覆盖作者修改。

0.18.0 实现验证为 299/299 项相关 EditMode 测试通过，最后图编辑器调整后复验 15/15；两批范围重叠，不累计为独立用例数。0.18.1 只修订文档，不新增运行验证结论。消费项目、独立 Player 和设备端仍须另行验收。

## 消费项目迁移

1. 开发仓库已完成此能力的模板保存与验证；消费项目接收前仍需按既有发布流程发布包含该模板的新 `com.ember` tag。模板版本不能充当框架包版本，也不能据此推断已经发布。
2. 消费项目备份未提交修改及模板旧基线，通过 `Ember/UPM Manager` 升级框架。不得手改 manifest/lock，不得改 PackageCache。
3. 模板新增能力属于 minor 升级，不能按同 minor 的 patch 增量规则处理。根据现有模板冲突恢复流程保护修改后部署/恢复，或对照新模板人工迁移。Package 升级本身不会更新已部署 Assets。
4. 对照迁移 Narrative 运行时、资产类型、编辑器、NovelSave 存储及保存页改动；保留消费端中文标题、折叠等本地改动，不能假定它们已回流。旧剧情节点先不改，运行回归后再逐段替换长回线和抽取支线流程。
5. 抽取流程时同时迁移内部节点归属、入口、结果与所有调用点。剧情结构改变会使相关旧存档的语义指纹失配；明确告知玩家从章节或新档重开，除非消费项目另行实现经过验证的版本迁移。
6. 在消费端重新执行循环、取消、嵌套、存档、重复输入和小游戏退出回归。开发仓库测试不能替代消费项目验收。
