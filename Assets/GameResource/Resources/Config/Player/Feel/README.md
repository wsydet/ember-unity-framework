新风格均采用松键限速短跳（分别6/5u/s），不启用边缘悬停或起跳早期水平接管。墙滑速度分别1/2u/s，快速墙滑10u/s；墙跳水平7/8、竖直15/17u/s，二段跳竖直15/17u/s。其他已实现动作沿用基础预设，包括0.1s离墙保护、已有回墙修正、挂边/翻越时长、下穿和踩头速度。普通落地停顿、重落地和翻滚均保持关闭，可在 Movement 中独立开启；对应专项试跑预设仍保留。

能力是否启用、默认解锁、次数和 CD 由 PlayerPowers 及其定义唯一管理，不复制进 Feel。四套预设可复用当前7 Ability/2 Skill完整示例；需要对应正式19状态图、Gameplay方向/跳跃/冲刺输入及 Entity Motor/Sensors。换 Feel 不修改 Powers，不补资源，实际动作仍按环境及当前状态判断。冲刺保持水平、地空独立 CD、动作保存拒绝；风格名称不改变这些已确认规则。

## 2026-10-12 物理实测

Unity 6000.5.4f1，隔离 PhysicsScene2D，步长.02s，1×1.75无摩擦方块，正式状态图与能力装配，水平地面。全跳按住一次跳跃至落地；短跳在第一物理步后松键；起步记录达到地面目标速度99%的时间，刹车记录速度小于.01u/s的时间。离散采样时间精度为一个物理步。数值只代表上述测试条件，不是最终关卡、任意碰撞体或任意物理步的承诺。

## 预设比较、独立另存与参考恢复（R11.2a）

当前从统一玩家开发工具使用完整方案的比较、复制和参考恢复。以下是 R11.2a 的旧 Profile 工具记录；旧 `Tools/Ember/Player/预设比较与另存` 不再注册菜单，旧草稿仅保留在高级区域。旧工具当前与参考均为真实 PlayerFeelProfile；差异包含 Movement、Jump、Input 的嵌套字段，左值为当前、右值为参考。比较不会求值 Guard 或更改运行数据。

“独立另存为”创建 Profile、Movement、Jump、Input 四份新资产，任一路径已存在即拒绝覆盖。参考恢复保留当前三个配置的身份/引用，将参数恢复为明确选择的参考预设（例如 Base）；这是恢复参考参数，不是从模板快照覆盖项目文件，也不保证参考资产从未被编辑。共享分组会影响所有引用者，应先独立另存。支持 Ctrl+Z / Ctrl+Y，恢复后仍需“保存当前预设资产”；不会切换正式 PlayerConfig、改 Powers、重置存档或应用到已运行实例。

## 运动曲线与片段实测（R11.2b）

从统一玩家开发工具的曲线入口，或蓝图中真实运行实例的“运动曲线与实测”入口打开。窗口绑定宿主和FSM会话ID；会话结束或被恢复替换后明确断开，不自动改选。可以显式选择宿主当前会话重新观察。

每个编辑器会话由玩家唯一物理驱动记录最多512步；时间为累计实际执行物理步的游戏秒，暂停不采样。曲线包含本步提交水平/竖直速度、刚体实际提交重力倍率，以及物理步开始观测位置Y、缓冲和土狼剩余时间（输入窗口在本步末衰减前）。位置通常来自上一步模拟结果；不把本步提交速度冒充碰撞后的速度，也不声称有限采样包含步间峰值。

最近普通Jump状态片段报告相对首次采样位置的最大观测上升、峰值相对时间、片段持续和结束状态；短跳、碰顶或动作切换均会截断。这是状态片段实测，不能代替完整自由轨迹或归因到某个未经评估的Guard。准备时基础公式估算另列，参数编辑不会改变当前会话已捕获值。

读取和窗口重绘不新增样本、不驱动FSM或物理、不消费输入。环形记录随会话替换/停止清理，未写入SO/存档/布局；代码受UNITY_EDITOR条件限制，发行编译排除。真实构建验证仍由后续综合验收明确记录。

## Visual、角色尺寸与白盒尺度（R11.2c）

从统一玩家开发工具的“玩家配置”页签定位 Prefab 表现／碰撞；旧尺度草稿位于高级区域。进入正式玩家 Prefab 编辑模式后，工具读取 EntityFacing2D 的真实 Visual 引用和 EntitySensors2D 的真实 Shape，不按节点名称猜测。默认 PlayerBlock 仍为 1×1.75，根节点保持单位缩放。

替换美术时编辑独立 Visual 的 Sprite、颜色与局部变换；其内部可继续制作动画/其他表现。单 Simple Sprite 可显式拟合当前 BoxCollider2D：计算包含 Sprite 轴心、PPU 和翻转的 bounds，只改变 Visual，不改物理和状态。复杂层级、额外渲染器或携带碰撞体时不自动拟合。支持 Undo/Redo，Prefab 保存使用 Unity 自带编辑流程；注意 Prefab 编辑模式可能开启自动保存。

调整尺寸时直接编辑实际 BoxCollider2D Size/Offset，并核对地面/墙面探测距离。检测基于同一 Shape Cast，因此形状随碰撞体变化；探测延伸距离仍是独立世界单位。下方明确选择需要核对的预设，修改挂边 Reach/VerticalReach/GripInset/Skin 等真实 Movement 字段；共享 SO 会影响所有引用者，建议先独立另存。不会自动推断速度、重力、时间或能力的缩放关系。参数/Prefab 保存后重新试跑，再依次检查低顶、窄通道、墙面、单向平台、翻越空间和落地/反弹；出生中心至少留出半个碰撞高度，正式出生配置与白盒位置分别配置。

窗口开启时，白盒 Scene 视图提供以世界原点为基准的刻度：水平每1u一格、每5u标值，高度0—15u逐格标值，水平标尺跟随 Scene 视图观察位置。刻度仅由编辑器绘制，不添加场景对象、碰撞或发行依赖；Prefab 编辑模式不显示白盒标尺。Game 内原有白盒方格继续作为试跑参照。
