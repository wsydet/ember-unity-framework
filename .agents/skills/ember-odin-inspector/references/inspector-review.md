# Odin 面板检查依据

## 证据优先级

当前版本的实际代码/复现结果优先于历史经验。需要查版本行为时使用该版本的官方文档；无法验证就标为待确认。

Ember 在 Unity 6000.5.4f1、Odin 4.0.2 的历史记录中观察过 HorizontalGroup 与 ShowInInspector/计算属性混用时布局异常；未确证其引擎或插件根因，也未证明其他版本普遍存在。遇到类似现象先检查 Drawer、动态状态和 Layout/Repaint，不把组合本身判为错误。

## 有效检查点

- 分组路径及动态字符串解析是否指向预期区域；同名 ButtonGroup 是否把无关按钮合并。
- ShowIf/HideIf/EnableIf 的成员是否存在、访问是否有效、是否在绘制期间产生副作用。
- ShowInInspector 仅展示并不等于 Unity 序列化；计算属性和调试展示不应被自动改造成序列化字段。
- 改变 public/属性/字段之前检查调用方、序列化数据、Unity Undo/脏标记以及 FormerlySerializedAs 等迁移需求。
- 同一 IMGUI 周期 Layout 与 Repaint 的控件数量/顺序应一致；异步完成时更新待应用数据，再在下一轮 Layout 固定快照。
- 资产/场景引用限制与实际用途一致，空引用依据代码是否允许判断，不仅依据特性名称判断。

优化应以面板实际可读性和操作结果为目标；不要为了统一风格改动产品业务逻辑。
